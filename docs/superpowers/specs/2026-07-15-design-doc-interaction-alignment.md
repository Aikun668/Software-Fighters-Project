# 设计文档交互对齐规格

## 目标

在不接入后端、Agent 或真实导出的前提下，使前端演示中的布局、模块入口和可见按钮严格遵循 `temp_file/design-file` 的交互定义。每个可见操作都必须产生明确的前端状态、弹窗、跳转或演示反馈，不能只保留装饰性按钮。

本轮坚持既定的暖白编辑式学习空间视觉语言，不重做调色板、字体或全局壳层。

## 范围与优先级

### P0：对话辅导页与侧边栏

这是所有模块的主要入口，先完成。

#### 对话模式

- 支持 `auto`、`exercise`、`resource`、`plan`、`visualization` 五种模式。
- 输入框工具栏的模式选择器可展开并切换模式。
- 每种模式定义：标题/说明、输入框 placeholder、快速示例、发送后的静态结果类型。
- 空会话显示五张快捷模式卡片；点击卡片仅切换模式并填充示例，不自动发送。
- 从资源工坊跳转时进入 `resource` 模式；从练习中心、学习计划、知识图谱进入对话时携带对应模式或主题参数。

#### 会话状态

- 路由采用 `/question-nav-chat?conversationId=<id>&mode=<mode>`。
- 新建对话进入空状态；发送第一条消息后生成本地会话，标题由首条内容截断生成。
- 已有对话显示标题栏、模式、创建日期和消息数。
- 标题栏提供重命名、删除确认、Markdown 导出（静态下载或明确的演示反馈）。
- 消息区分别渲染用户消息、AI 消息、模式标签和消息操作：复制、重新生成、赞/踩。
- 右侧会话面板提供收起/展开状态，展示该对话的模式、关联资源/练习/计划入口。

#### 侧边栏

- 历史会话点击后更新 `conversationId` 并切换当前消息。
- 当前会话显示选中态；新建、重命名和删除与会话页保持同一份本地状态。
- 历史列表展开状态、侧边栏收起状态、当前会话和每个会话草稿使用 localStorage 保存。
- 现有的六个模块入口保持，设置/帮助/学习者按钮需有轻量菜单或提示反馈。

### P1：五个业务模块的按钮语义

每页以其设计文档为唯一交互依据，保留目前已完成的视觉布局。

| 页面 | 必须对齐的交互 |
| --- | --- |
| 学情分析 | 刷新加载、分析依据、诊断抽屉筛选、画像纠错、趋势切换、知识点与行动卡跳转 |
| 学习计划 | 计划下拉、新建计划、任务完成/编辑/删除、仅看未完成、折叠路径、AI 调整预览、图谱任务联动 |
| 知识图谱 | 掌握状态筛选、缩放/重置、节点详情、移除确认、关联节点跳转、由其他模块携带节点聚焦参数 |
| 练习中心 | 开始/跳过、选择/简答/代码题、题目导航、反馈操作、完成总结、历史查看 |
| 资源工坊 | 搜索和类型筛选、资源预览、闪卡翻转、项目步骤、导出菜单、删除确认、资源生成模式跳转 |

### P2：演示状态与容错

- 所有异步样式操作使用短暂加载状态和固定本地数据，不调用后端。
- 删除、AI 调整、导出等高影响动作必须先给出确认或结果反馈。
- 空状态和筛选无结果状态按对应设计文档呈现。
- 不实现真实 Cytoscape 图布局、SSE、真实文件导出或后端持久化；以稳定的静态演示状态替代。

## 状态与数据边界

- 新增一个前端会话状态模块，集中维护会话列表、消息、当前模式、草稿和关联产物。
- 页面组件不直接各自维护会话列表；侧边栏和对话页通过同一状态模块协作。
- 五个业务模块维持本地 mock 数据，但跳转参数统一为：`topic`、`mode`、`nodeId`、`exerciseId`、`resourceId`、`planId`。
- localStorage 只保存演示所需的 UI 状态；刷新页面后可恢复会话和侧边栏，不访问 API。

## 验收标准

1. 从根路由进入页面后，不需要登录即可完成完整 Demo 流程。
2. 对话页可以切换全部五种模式，并在模式切换、发送、历史切换后保持页面语义一致。
3. 侧边栏的对话管理操作能影响对话页，反之亦然。
4. 五个业务模块所有文档定义的 P0/P1 按钮均存在，并产生可观察结果。
5. 各模块之间的跳转携带上下文，跳转后页面可解释“为什么来到这里”。
6. `npm run build` 通过；使用浏览器逐页验证入口、弹窗、筛选、跳转和状态切换。

## 验证顺序

1. 新建对话 → 选择资源生成模式 → 输入主题 → 静态资源结果 → 前往资源工坊。
2. 从资源工坊 → 对话生成，确认自动切换资源模式。
3. 从学情分析的薄弱点 → 图谱节点 → 专项练习 → 完成反馈 → 返回学情分析。
4. 在学习计划完成任务 → 检查计划统计与图谱跳转。
5. 刷新浏览器，确认侧边栏与当前会话状态恢复。

## 非目标

- 不连接后端、Agent、数据库、SSE 或真实文件下载。
- 不改变已确认的整体视觉方向。
- 不进行与设计文档对齐无关的重构。
