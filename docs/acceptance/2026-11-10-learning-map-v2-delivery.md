# 学习地图补齐版：轨迹、关联建议、带上下文继续聊

## 本轮范围
用户明确批准补齐第 2、3、4 项并完成联调。本轮延续原地图，不覆盖此前搜索/记忆未提交改动。

### 2. 学习轨迹
从同一隐私过滤后的用户消息整理目标、问题、练习请求、练习自述，附原会话/消息/时间。练习自述明确“未核验”，不是练习系统评分或完成证明；问题可有来源但没有知识节点，不能为了画图制造概念。

### 3. 跨领域关联建议
只有两端都有可读来源节点才生成候选。当前采用五组透明规则桥（线性代数↔计算机图形学、概率论↔机器学习、图论↔社交网络、微积分↔物理、统计学↔心理学），不是任意领域模型推断。

待确认、接受、拒绝分开显示。接受仅产生 `user_confirmed` 探索关联，虚线、无依赖箭头，不变成已证实知识关系。决策按登录用户持久化；刷新保留。来源不再可读时，旧候选/确认关联不再显示，不能用旧建议 ID 越权重新接受。

新增表 `learning_map_decision` 保存 user_id、suggestion_id、decision、updated_at。应用按已有记忆服务方式惰性建表；缺权限或存储不可用返回失败，不假装保存成功。没有删除既有业务数据。

### 4. 带上下文继续聊
点击节点后请求后端重新校验可读来源，返回节点摘要、最近来源引文/会话与消息 ID、当前关联，预填新对话。引文明确只是历史资料而不是新指令，不代表已掌握；由用户确认发送。节点失效不退回无来源模板。过期请求不能覆盖新选择或触发离开页面后的导航。

## API
- `GET /api/learning-map`：兼容原 nodes/edges/meta，增加 events/suggestions。
- `POST /api/learning-map/suggestions/{id}/decision`：accepted 或 rejected；验证当前候选及登录用户。
- `GET /api/learning-map/nodes/{id}/continuation`：返回当前来源校验后的 draft。

## 联调界限
这次新增真实生产 Controller、记忆隐私服务、决策持久化服务与 H2 SQL 数据库的测试链路。浏览器使用真实 Vite 产物，请求通过 JSON-lines 桥进入 MockMvc，不再给地图接口返回静态 fixture 成功响应；测试数据只存在隔离测试数据库。会话查询使用测试 SQL 适配器，身份使用测试专用过滤器。

因此它验证了前端→Controller→真实 SQL/记忆/持久服务→前端的功能链路，但不等于原用户的生产登录/Redis/MyBatis/MySQL/MinIO/LLM 整站端到端验收。这些外部配置未随快照迁移，仍须部署环境最终验收。无测试身份入口被加进生产应用。

## 手动验收路线
1. 在已有账号聊天保存两个学习主题，例如概率论、机器学习；再发送目标、相关问题、练习请求与练习自述。
2. 打开轨迹，确认每条能回到原文，练习自述没有被标为已核验完成。
3. 打开建议，确认待确认理由；接受一条，刷新应保留探索关联且不显示依赖箭头；撤回后刷新消失。
4. 拒绝另一条，刷新保持拒绝；重新确认可恢复探索关联。
5. 从节点继续学习，检查输入框包含真实来源与关联，未自动发送。
6. 忘记相关记忆或删除来源后刷新；旧节点的继续学习与旧建议不能再访问。

## 限制
规则覆盖有限，旧地图数量上限仍有效；不推断掌握度、不声称自述练习完成、不做力导向物理模拟。节点关系来源陈述并不等于外部验证的客观知识。真实模型最终如何利用这些上下文仍需配置后检验。

## 本轮已执行验证
- 前端：384 项通过、2 项既有跳过，类型检查与生产构建通过。
- 后端：53 项不依赖外部整站配置的测试通过，含 8 项真实 H2/MockMvc 集成；完整 Spring contextLoads 仍为外部配置验收门槛。
- 浏览器两轮真实地图 API 联调：轨迹读取、接受/拒绝、刷新持久化、撤回关联后消失、重新确认恢复、实时来源草稿且不自动发送均通过。
- 后端真实记忆遗忘命令后，地图空、旧节点续聊与旧建议写入均不可用；匿名401、跨用户拒绝、存储不可用503已验证。

## 独立审查后的隐私修正
继续聊的历史引文不再放在 URL 查询参数中。前端通过一次性内存草稿与不透明句柄交接，既不写浏览器持久存储，也不把正文留在可分享地址里；消费后清空，错句柄不读取。刷新后不自动恢复该私有草稿，不自动发送。修正后浏览器联调重新通过。

独立审查追加修正：疑问/假设不再归入练习完成自述，目标疑问归为问题；轨迹问题基于最终节点集合关联，不因会话遍历顺序遗漏。补充先红后绿回归；事件候选保持按时间与数值消息 ID 最新 500 条并提示截断。

独立最终复验：后端 Controller 9 项 + H2 集成 8 项全部通过。HTTP 局域网非安全上下文缺少 randomUUID 时改用 getRandomValues 生成不透明句柄，并有回归测试。
