# 个人学习地图 MVP · 云端候选版

> 本文保留第一阶段验收记录。后续轨迹、关联建议、上下文续聊已补齐，当前范围见 `2026-11-10-learning-map-v2-delivery.md`。

## 做了什么
- 正式 `frontend` 的知识图谱页面不再显示六个示例节点、虚构掌握度或固定关联数。
- 新增登录保护的 `GET /api/learning-map`，从当前用户已经保存的对话及可核验的学习记忆生成地图。
- 同一概念去重；每个节点保存原文、会话、消息与时间线索。明确前置关系才连线，共现不会连线。
- 全局 / 一跳局部、搜索、缩放、拖动、来源侧栏；打开来源对话；从节点预填一个新对话问题，由用户发送。
- 地图重读数据库投影，不另建容易失效的图数据库。删除源会话、遗忘边界会影响下一次读取。已有课程骨架接口留给原功能，不冒充个人数据。

## 方案取舍
1. **保存对话 + 确定性提取（本版）**：不新增模型调用、数据库或服务；可追溯、易测；代价是语言覆盖较窄。
2. 模型结构化提取 + 证据校验：更自然、覆盖更广，但要增加模型调用、超时重试、证据验证与误连评估。
3. 专用图数据库 + 向量检索：适合较大规模，不适合当前先跑通的目标。

本版不是任意自然语言语义理解，也不是 Obsidian 的完整替代。地图节点表示学习线索，不表示已掌握。力导向模拟、跨领域推荐和自动推断关系不在本版。

## 明确支持的验收对话
在现有登录账号中用新会话逐条发送并等保存后打开知识地图：
1. `我想学习线性代数`：出现可追溯节点。
2. `我想学习Python`：第二个独立点，不应仅因同场出现连线。
3. `线性代数是机器学习的前置知识`：机器学习 → 线性代数，有该句证据。
4. `反向传播是什么？`：出现学习问题节点，不自动宣称掌握。
5. `假设机器学习依赖Python` 或 `机器学习依赖Python吗？`：不建立确定关系。
6. `[[梯度下降]]`：显式标记学习概念。
7. 查看节点来源，进入原会话；点击继续学习，只预填，不自动发消息。
8. 使用现有记忆遗忘命令，再刷新，确认被隐私边界过滤的旧内容不重现。

## 定量门槛
- 测试集中无证据连线 0 条；否定/疑问/假设表达确定连线 0 条。
- 展示节点与关系的证据引用覆盖率 100%。
- 相同规范化概念重复节点数 0；外用户数据泄露 0。
- 空、失败、隐私状态不可读取场景中示例数据回退 0。
- 节点继续学习自动发送次数 0。

以上是有限测试集的门槛，不是对所有自然语言输入的准确率承诺。详细执行结果在验收记录中补充。

## 运行与验收范围
使用原项目的登录、Java 网关、数据库配置启动。新增端点只依赖 Java 与原数据库，图谱读取不新增 Python/LLM 调用；继续聊天仍依赖原聊天服务。

云端副本没有本地数据库、会话令牌或模型密钥。因此组件测试与截图中的数据属于隔离测试夹具，不表示已经跑通你的真实账号端到端。原电脑的源码和数据没有被覆盖，也不会自动同步本候选版。

## 数据范围与剩余限制
- 最近 100 个会话，每个最近 500 条消息；最多 500 个节点、1000 条边、每节点最近 20 条来源。达到上限明确提示。
- 单条超过 8000 字的消息跳过并标截断。当前以中文明确学习表达和显式 `[[概念]]` 为主，不做通用实体抽取、同义词合并或隐含代词指代。
- 关系代表来源中明确陈述的依赖/前置关系，不代表经过外部事实验证的科学结论；未实现完整的跨消息矛盾消解。
- 读取时重建，刷新或重新进入地图后更新；不是聊天流中的即时动画推送。
- 初版布局为可拖动、缩放的确定性布局，不是力导向物理模拟。

## 回本地的建议
本交付是云端候选，不会自动覆盖本机。先保留现有工作树备份，再对照变更清单逐文件合并；若本机此后又有修改，不能整包覆盖。沿用原本 `.env` / 环境变量和数据库，不用云端快照中的脱敏配置替换真实配置。使用现有账号登录，不必新建测试账号。至少完成上面的8步真实会话验收再合并上线。
