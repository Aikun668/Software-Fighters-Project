# 动态计划改动日志

## 2026-11-10 · 第一版（最终验收见交付报告）

### 范围
- 原学习计划页以固定数组和模拟等待表现 AI 调整，不能证明刷新后的持久化。本次替换为真实接口驱动的模块化计划。
- 新动态计划与历史 research 生成路径目前分开保存；不把历史演示或练习分数自动转换为新计划完成。
- 沿用 Vue + Java + 现有数据库连接。新计划由认证用户隔离，并以服务端版本号防止旧页面覆盖新进度。
- AI 名义的任意自动改写不属于本 MVP。规则支持的局部调整会展示明确差异，确认才应用；未识别请求不能悄悄改计划。
- 完成是用户自报，不代表知识掌握；没有自动提醒。

### 固定交付质量要求
创建和重读、暂停断点、续学、局部调整预览/取消/确认、期限冲突、保留完成、撤销、跨用户及过期版本、桌面/窄屏、现有功能回归。具体通过数和限制只记录真实执行结果，不预填。

### 发布前独立审核修复

- 保存中的计划路由切换延后重载，确保 URL 和显示的计划一致。
- 延期任务先重新列入后才能作为调整目标。
