### 3.2 `ai-service/prompts/tutor_agent/system.yaml`（只许末尾追加 → 落点说明）

**落点技术决策**：本文件物理末尾是 `user_template:` 块（仅含 `{message}`，被 `BaseAgent` 以 `key="user_template"` 消费进 **user 消息**）。若按物理 EOF 追加，规则会污染每条用户消息且 system 提示词完全读不到——与任务意图（教 LLM）相反。因此追加块落在 **`system: |` 块的内容末尾**（"优先使用知识库……"之后、`user_template:` 之前）：这是"system 提示词的末尾"，全部为纯新增行，不删不改任何现有行，他人改动一行不少。

追加内容（显眼标记 `# ====== T007 可视化图表（ui-block 围栏）======`），要点与代码口径逐条对齐：

- 触发条件：讲解注意力机制 / Attention Mask / 自注意力 / causal LM 等概念时，**回答最末尾**附加围栏；无关概念不加；每次至多一个
- 围栏写法：三个反引号紧跟 `ui-block`（恰为 ui-block，无多余字符）独立成行开启，闭围栏独立成行 —— 对齐 `_UI_BLOCK_RE`（3-backtick、info string 恰为 ui-block、开/闭独立成行）
- JSON：`{"type": "attention_matrix", "version": 1, "props": {...}}` 顶层只许 3 字段；props 只许 `tokenCount`（3..8 整数）、`mode`（"causal"/"bidirectional"）、可选 `queryLabels`/`keyLabels`（字符串数组，长度 = tokenCount）—— 对齐 `parse_ui_block` 校验器（envelope 未知字段拒绝、D-007 weights 拒绝）
- **绝不输出 weights**（D-007，真实或编造都不行）
- 围栏会被系统剥离转成图表，不要在围栏外复述 —— 对齐"失败不吞正文 + 剥离后正文纯 Markdown"管线语义
- 附完整示例围栏（含中文 token labels），LLM 遵循示例远好于遵循描述

安全性核对：示例 JSON 中 `{` 后紧跟 `"`，不匹配 `interpolate_variables` 的 `\{(\w+)}` 模式，不会被占位符替换误伤；无 `{{snippet:}}` / `{{#if}}` 序列。

## 五、只读调查：response_sanity.py 是否剥/改 ui-block 围栏

**结论：不会。** 当前工作区版本（他人 WIP）的 `check_response` 是纯检查器（docstring 明示"确定性、无 LLM、**不改写内容**"），返回 `SanityResult/SanityOutcome` 让调用方决策，自身不剥离、不修改任何文本。剥离围栏的职责在 `visualization_blocks.py`（作用于最终 payload，与 sanity 检查是两个环节）。逐项核对检查器对 ui-block 围栏的相容性：

| 检查项 | 对含 ui-block 围栏正文的影响 |
|---|---|
| `_has_raw_chart_config` | 先用 ```` ```[\s\S]*?``` ```` 剔除所有闭合围栏对再查 `_CHART_CONFIG_RE`；且该正则只认 bar/line/pie/scatter/... 图表类型与 Chart.js 配置键（datasets/scales/ticks/legend/...），`"type": "attention_matrix"` 与 tokenCount/mode/queryLabels 均不在特征表 → 不误判 |
| `_has_raw_mermaid` | 同样先剔除闭合围栏 → 不误判 |
| `_has_prompt_leak` | 要求整段 strip 后以 `{` 开头 `}` 结尾且含内部 JSON 键（system_prompt/built_context/...）→ Markdown 正文 + 围栏不满足 → 不误判 |
| `_has_internal_marker` | 只精确匹配"内容核查提示"/"以下内容置信度较低" → 不误判 |
| `_is_truncated` | ``` 出现奇数次才判截断；闭合围栏贡献 2 次（偶数）→ 不误判 |
| `_has_heavy_repetition` | 片段需重复 ≥5 次；围栏 JSON 单次出现、内部字段各不相同 → 不误判 |
| `_has_language_mismatch` | 文本含 ``` 时**直接跳过**语言检查（`_has_language_mismatch` 里 len<80 或含 ``` 提前 return False）→ 天然豁免 |

唯一边界：**未闭合**（截断）的 ui-block 围栏会走 truncated/raw_chart_config 的 RETRY_ONCE——这是截断场景的合理失败处理（该轮回答本就不合格），不属于对合法围栏的破坏。
