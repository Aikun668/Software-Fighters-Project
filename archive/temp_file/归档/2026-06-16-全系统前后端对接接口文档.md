## 一、前端如何理解 AI 服务

### 1.1 万能入口：`POST /api/chat`

这是**最重要的接口**。所有模糊输入、自然语言问题，全部走这里。前端不需要判断用户意图，AI 内部自动路由。

```
用户输入 → /api/chat → Python 分析意图 → 分发到对应 Agent → SSE 流式返回
```

**请求**（前端 → Java → Python）:
```json
{
  "message": "帮我写一个用PyTorch训练CNN的代码",
  "mode": "auto",
  "user_id": 1,
  "student_profile": {
    "knowledge_base": 50,
    "cognitive_style": "visual",
    "learning_goal": "掌握深度学习",
    "weak_points": ["数学"],
    "learning_pace": "moderate",
    "interest_direction": ["CV"]
  },
  "messages": [],
  "images": []
}
```

**请求参数详解**:

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `message` | string | **是** | 用户的自然语言输入，啥都可以写 |
| `mode` | string | 否 | `"auto"`（默认，自动判断）/ `"plan"`（学习计划）/ `"resource"`（资源生成）/ `"exercise"`（练习）|
| `user_id` | int | 否 | 用户 ID，默认 1 |
| `student_profile` | object | 否 | 6 维学生画像（见下文），**Java 从数据库读取后传入** |
| `messages` | array | 否 | 历史对话消息列表，**Java 从数据库读取后传入** |
| `images` | array | 否 | 用户上传的图片 URL 列表 |
| `conversation_id` | int | 否 | 会话 ID，Java 管理 |
| `style` | string | 否 | `"standard"`（标准回答）/ `"socratic"`（苏格拉底式引导），仅答疑场景生效 |

### 1.2 AI 内部路由规则（前端不需要管，但要理解）

当你传 `mode: "auto"` 时，Python 内部按以下优先级判断用户想要什么：

```
输入: "帮我写一个PyTorch CNN代码"
  ↓ 优先级 1: 关键词规则匹配
  ├─ "写代码" "代码" "api" "demo" → 路由到 CodeAgent（代码资源）
  ├─ "可视化" "动画" "架构图" → 路由到 InteractiveDiagramAgent（交互式图表）
  ├─ "思维导图" "梳理" "归纳" → 路由到 MindMapAgent（思维导图）
  ├─ "项目" "从零" "实战" "搭建" → 路由到 ProjectAgent（微型项目）
  ├─ "闪卡" "背诵" "考点" → 路由到 FlashCardAgent（记忆闪卡）
  └─ "是什么" "原理" "概念" "入门" "对比" → 路由到 ContentAgent（课程文档）
  ↓ 优先级 2: LLM 兜底（口语/方言/模糊表达）
  └─ 没有关键词命中时，LLM 判断意图
```

**所以前端不用纠结用户说了什么——全部丢给 `/api/chat`，mode 用 `auto` 就行。**

### 1.3 SSE 响应格式

`/api/chat` 返回 SSE（Server-Sent Events）流。每行格式：

```
data: {"type": "<事件类型>", ...字段}\n\n
```

**通用事件类型**（所有接口都可能出现）:

| type | 含义 | 携带字段 |
|------|------|----------|
| `token` | 逐字文本输出 | `content` (string) |
| `meta` | 元信息 | `conversation_id` (int) |
| `progress` | 进度更新 | `stage`, `progress` (0.0-1.0) |
| `content` | 结构化内容块 | `stage`, `data` (object) |
| `recommendation` | 练习推荐 | `data.type="exercise_recommendation"`, `data.knowledge_node_id`, `data.node_name` |
| `error` | 可恢复错误 | `content` (string) |
| `done` | 流结束 | 无（或含最终 data） |

**前端处理模板**:
```javascript
// 用 fetch + ReadableStream（不是 EventSource！需要 POST）
const response = await fetch('/api/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ message: "你好", mode: "auto", user_id: 1 })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;

  const text = decoder.decode(value, { stream: true });
  const lines = text.split('\n');

  for (const line of lines) {
    if (line.startsWith('data: ')) {
      const event = JSON.parse(line.slice(6));
      switch (event.type) {
        case 'token':
          appendToChat(event.content);    // 逐字显示
          break;
        case 'recommendation':
          showExerciseButton(event.data); // 显示「去练习」按钮
          break;
        case 'done':
          finalizeResponse();
          break;
        case 'error':
          showError(event.content);
          break;
      }
    }
  }
}
```

## 三、核心接口详解

### 3.1 资源生成 — `POST /api/resources/generate`

**请求**:
```json
{
  "topic": "卷积神经网络",
  "resource_type": "code",
  "user_id": 1,
  "student_profile": {
    "knowledge_base": 50,
    "weak_points": ["数学"]
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `topic` | string | **是** | 资源主题，最长 2000 字符 |
| `resource_type` | string | 否 | `"document"` / `"interactive_diagram"` / `"code"` / `"project"` / `"mindmap"` / `"flashcard"`。**不传则由 AI 自动判断** |
| `student_profile` | object | 否 | 6 维画像，用于个性化内容 |
| `user_id` | int | 否 | 用户 ID |

**SSE 事件**:
```json
// 阶段开始
{"type": "progress", "stage": "plan", "message": "正在规划大纲...", "progress": 0.1}

// 内容块（边生成边返回）
{"type": "content", "stage": "content", "data": {"type": "section", "heading": "CNN概述", "content": "..."}}

// 阶段结束
{"type": "progress", "stage": "content", "message": "文档生成完成", "progress": 0.8}

// 最终结果
{"type": "done", "data": {
  "content_blocks": [
    {"type": "section", "heading": "概述", "content": "CNN是..."},
    {"type": "code", "heading": "PyTorch实现", "content": "```python\n..."},
    {"type": "mindmap", "heading": "知识图谱", "content": "{...}"},
    {"type": "mermaid", "heading": "架构图", "content": "graph TD\n..."},
    {"type": "flash_cards", "heading": "记忆闪卡", "content": "[...]"},
    {"type": "callout", "heading": "关键要点", "content": "..."},
    {"type": "project", "heading": "项目", "content": {...}}
  ],
  "response": "已为你生成CNN学习资源"
}}
```

**6 种资源类型 + 对应 content_block.type**:

| resource_type | 生成内容 | block.type |
|---------------|---------|------------|
| `document` | 课程文档（分节讲解） | `section` / `callout` |
| `code` | 代码案例 + 诊断修复 | `code` / `section` |
| `project` | 微型练习项目（含里程碑） | `project` |
| `mindmap` | 思维导图 + Mermaid 图谱 | `mindmap` / `mermaid` |
| `flashcard` | 记忆闪卡（问答对） | `flash_cards` |
| `interactive_diagram` | 交互式可视化（D3.js/SVG） | `section`（含 HTML） |

**请求**:
```json
{
  "user_id": 1,

```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `messages` | array | **是** | 完整对话历史，**Java 从数据库读取后传入** |
| `user_id` | int | 否 | 用户 ID |
| `student_profile` | object | 否 | 画像用于个性化回答 |

**SSE 事件**: `token`（逐字输出）→ `done`

### 3.3 练习生成 — `POST /api/exercise/generate`

**请求**:
```json
{
  "topic": "反向传播",
  "knowledge_node_id": "backprop",
  "strategy": "weakness",
  "count": 5,
  "difficulty": "medium",
  "user_id": 1,
  "student_profile": { "weak_points": ["反向传播"] }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `topic` | string | 否 | 题目主题（与 `knowledge_node_id` 二选一，后者优先） |
| `knowledge_node_id` | string | 否 | **知识图谱节点 ID（优先）** |
| `strategy` | string | 否 | `"weakness"`（薄弱点）/ `"review"`（错题同类）/ `"new"`（新题） |
| `count` | int | 否 | 题目数量，默认 3，范围 1-20 |
| `difficulty` | string | 否 | `"easy"` / `"medium"` / `"hard"`，默认 medium |

**SSE 事件**: `token` → `content`（题目块）→ `done`

### 3.4 题目评分 — `POST /api/exercise/grade`

**请求**:
```json
{
  "type": "choice",
  "user_answer": "B",
  "correct_answer": "B",
  "choices": ["A", "B", "C", "D"],
  "multi": false,
  "points": 1
}
```

| 字段 | 说明 |
|------|------|
| `type` | `"choice"` / `"short_answer"` / `"code"` |
| `user_answer` | 用户答案 |
| `correct_answer` | 正确答案（选择题必传） |
| `reference_answer` | 参考答案（简答题/代码题传） |

**响应**:
```json

### 3.10 计划状态 — `GET /api/plans/{planId}/status?user_id=1`

**响应核心字段 — `soft_landing`**（中断回归）:

| strategy | 触发条件 | 前端行为 |
|----------|----------|----------|
| `continue` | 闲置 ≤ 3 天 | 直接继续 |
| `warmup` | 闲置 4-7 天 | 出 1 道热身题 |
| `regression_check` | 闲置 > 7 天 | **走两阶段回归检测流程** |

**回归检测两阶段流程**:
```
阶段 1: POST /api/plans/{planId}/regression-check  (不带 answers)
  → AI 出题检测遗忘程度
  → 前端展示题目，用户作答

阶段 2: POST /api/plans/{planId}/regression-check  (带 answers)
  → AI 判分 + 重排学习计划
  → 前端展示调整后的计划
```

## 六、Java 后端转发模板

### 6.1 SSE 流式转发

```java
@PostMapping(value = "/api/chat", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public SseEmitter unifiedChat(@RequestBody UnifiedChatRequest request) {
    SseEmitter emitter = new SseEmitter(300_000L); // 5 分钟超时

    aiClient.post()
        .uri("/internal/api/chat")
        .bodyValue(request)
        .retrieve()
        .bodyToFlux(String.class)
        .subscribe(
            data -> {
                try {
                    emitter.send(SseEmitter.event().data(data));
                } catch (IOException e) {
                    emitter.completeWithError(e);
                }
            },
            error -> {
                try {
                    emitter.send(SseEmitter.event()
                        .data("{\"type\":\"error\",\"content\":\"AI服务暂时不可用\"}"));
                } catch (IOException ignored) {}
                emitter.complete();
            },
            () -> emitter.complete()
        );

    return emitter;
}
```

### 6.2 JSON 转发

```java
@PostMapping("/api/exercise/grade")
public ResponseEntity<?> gradeExercise(@RequestBody GradeRequest request) {
    try {
        Map<String, Object> result = aiClient.post()
            .uri("/internal/exercise/grade")
            .bodyValue(request)
            .retrieve()
            .bodyToMono(Map.class)
            .block(Duration.ofSeconds(30));
        return ResponseEntity.ok(result);
    } catch (Exception e) {
        return ResponseEntity.status(502)
            .body(Map.of("error", "AI服务暂时不可用"));
    }
}
```

### 6.3 转发注意事项

| 项 | 值 |
|----|-----|
| Python 前缀 | 所有端点加 `/internal` |
| SSE 超时 | 300 秒（5 分钟） |
| JSON 超时 | 30 秒 |
| 错误降级 | AI 不可用时返回 `502` + 友好提示，**不要 500** |
| Content-Type | SSE 必须 `produces = MediaType.TEXT_EVENT_STREAM_VALUE` |
