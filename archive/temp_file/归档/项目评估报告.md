## 三、架构设计评估

### 3.1 分层架构 ⭐⭐⭐⭐⭐

```
┌─────────────────────────────────────────┐
│  Vue3 Frontend (:5173)                   │
│  ElementPlus + Pinia + ECharts           │
│  SSE 流式接收 AI 响应                     │
└──────────────┬──────────────────────────┘
               │ REST / SSE
┌──────────────▼──────────────────────────┐
│  Java SpringBoot (:8080)                 │
│  用户管理/学习计划/资源管理/对话管理       │
│  JWT 认证 + MyBatis-Plus + Redis         │
│  所有数据组装后转发 Python                │
└──────────────┬──────────────────────────┘
               │ REST (internal)
┌──────────────▼──────────────────────────┐
│  Python FastAPI (:8001)                  │
│  LangGraph Agent 工作流                  │
│  纯 AI 推理，不持久化                     │
│  ChromaDB 向量检索                        │
└─────────────────────────────────────────┘
```

**评价**：经典的三层分离架构，职责清晰。Java 负责业务逻辑与数据持久化，Python 专注 AI 推理，双方通过标准 REST/SSE 协议交互。**"纯 AI 推理层不调 Java API、不持久化"的 Architecture #2 原则避免了循环依赖**，是良好的分布式设计实践。

### 3.2 多智能体协作设计 ⭐⭐⭐⭐⭐

| 智能体 | 职责 | 核心技术 |
|--------|------|---------|
| **ProfileAgent** | 对话式学习画像构建 | 增量提取 → 条目合并 → 周期性审计 → 响应生成 |
| **TutorAgent** | 智能答疑 | 苏格拉底追问模式、领域路由 |
| **ContentAgent** | 学习资源生成（文档/思维导图/拓展阅读/代码案例） | 多类型内容块生成 |
| **ExerciseAgent** | 个性化练习题生成 | 难度自适应、题型多样化 |
| **PathAgent** | 学习路径规划 | 知识图谱 + 遗忘曲线 + 软着陆 |
| **ChatCenter** | 统一路由中心 | 意图识别 → 模式分流 → Agent调度 |

**亮点**：
- ProfileAgent 实现了**增量提取**（只处理新消息）、**条目模型**（完整句子+置信度而非孤立标签）、**周期性审计**（10轮后审视已有条目）、**硬上限裁剪**（每维度最多8条）
- ChatCenter 实现了 `route → execute` 的双阶段管道，支持多层意图路由
- 苏格拉底追问模式根据历史轮数动态调整追问策略

### 3.3 LangGraph 工作流 ⭐⭐⭐⭐

所有 Agent 均基于 `BaseAgent` → `StateGraph` 模式，工作流节点清晰可追溯：

```
ProfileAgent:  extract → merge → audit → response
ResourceGen:   (多节点并行生成 → 校验 → 合并)
LearningPath:  (知识图谱构建 → 路径规划 → 遗忘检测)
```
