## 一、这次要解决什么

### 当前调用链（以 `/plans/{id}/today` 为例）

```
Java LearningPlanController.getTodayTasks()
  └─ POST /internal/plans/{id}/today
       └─ internal_api.get_today_tasks()          ← 114 行业务逻辑在 API 内
            ├─ 日期解析 / day_index             ← 计划域算法
            ├─ 累计 estimated_days 分桶          ← 计划域算法

```

```
Java LearningPlanController.getTodayTasks()
  └─ POST /internal/plans/{id}/today
       └─ internal_api.get_today_tasks()          ← 约 15 行：校验 → 1 个 Center 调用 → api_success
```

### 5.1 `PlanService` 新增纯算法（`app/services/plan_service.py`）

```python
@staticmethod

@staticmethod

@staticmethod

    steps: list[dict], *, day_index: int, completed_steps: int,
```

### 5.2 `PlanCenter` 新增业务入口（`app/centers/plan_center.py`）

```python
def __init__(self, ..., plan_service=None, exercise_center=None):
    self.plan_service = plan_service          # 默认 get_plan_service()
    self.exercise_center = exercise_center    # 默认 None → 惰性 _exercise_center()

async def today_tasks(self, *, plan: dict, steps: list[dict], start_date: str | None,
                      masteries: dict) -> dict
async def update_progress(self, *, plan: dict, steps: list[dict], masteries: dict,

                          activity_type: str, duration_minutes: int) -> dict
```

### 5.6 `internal_api.py` 收窄

每个路由目标形态（以 `today` 为例）：

```python
@router.post("/plans/{plan_id}/today")
async def get_today_tasks(plan_id: int, body: TodayTasksRequest):
    """返回今日应完成的步骤 + 每个步骤的资源建议。业务编排委派给 PlanCenter.today_tasks()。"""
    try:
        result = await _get_plan_center().today_tasks(
            plan=body.plan, steps=body.steps,
            start_date=body.start_date, masteries=body.masteries or {},
        )
        return api_success(result)
    except PlanNotFoundError as e:
        return api_error(ErrorCode.NOT_FOUND, str(e), status_code=404)
    except Exception as e:
        logger.error(f"Failed to get today tasks: {e}", exc_info=True)
        return api_error(ErrorCode.INTERNAL_ERROR, "获取今日任务失败", status_code=500)
```

- `create_plan_from_path` 已符合该形态，**不动**。
- `_compute_next_milestone` / `_get_plan_status_core` / `StepProxy` **删除**（前者需同步改 `tests/test_plan_center_api_contract.py:736` 的 `hasattr` 断言）。
- `get_plan_status_legacy` 保留独立路由（路径不同），内部同样只做 `plan_id` 提取 + 一个 Center 调用。
