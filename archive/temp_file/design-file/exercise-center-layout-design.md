## 一、设计原则

```
生成与练习分离 · 题目只在对话页生成 · 练习中心专注做题
─────────────────────────────────────────────────────────
· 题目在对话页生成 → 用户一键加入练习中心
· 练习中心 = 做题的地方，不在此处生成题目
· 三种题型：选择题 / 简答题 / 代码题
· AI 实时批改 + 深度反馈（不只给对错）
· 侧重理解与应用，不要填空题（偏记忆）
· 完成练习后 mastery 联动知识图谱 + 学习计划
· "去对话页出题"是唯一的生成入口
```

## 十二、数据模型

```
ExerciseSet（一套练习）:
  id: number
  title: string                    # "CNN 专项练习"
  description: string              # "卷积层 + 池化层 + 全连接层"
  source_conversation_id: number   # 来自哪次对话
  created_at: datetime
  status: "pending" | "in_progress" | "completed"
  questions: Question[]
  total_score: number              # 26

Question:
  id: number
  type: "choice" | "essay" | "code"
  question: string                 # 题目文字
  score: number                    # 分值
  hints: string[]                  # 提示列表
  options: string[]                # 选择题选项
  correct_answer: number           # 选择题正确答案索引
  reference_answer: string         # 简答/代码题参考答案
  analysis: string                 # 解析

UserAnswer:
  exercise_set_id: number
  question_id: number
  selected_option: number | null   # 选择题
  text_answer: string | null       # 简答/代码题
  score: number | null             # AI 批改得分
  feedback: string | null          # AI 批改反馈
  is_correct: boolean | null
```
