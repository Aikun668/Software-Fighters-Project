### 关键发现：明确产物 -8 的真相（须产品决策）

这 8 条「回归」全是**隐式裸主题词**（无祈使动词）：

```
二次函数，中等难度的 / 二叉树的题目，基础一点的 / 四级阅读理解
机器学习入门 / Python爬虫 / 前端入门 / 考研408 / TCP三次握手 / 知识点关系
```

- **旧 gate**：靠关键词碰运气命中（"题目"→EXERCISE、"入门"→RESOURCE…）。
- **新语义腿**：诚实判"这只是主题描述、不确定要干嘛"→ tutor_question。

**这不是 T4 的 bug**，是「隐式需求」的语义分歧：裸主题词该不该默认当「明确产物」。
旧路由是"规则碰运气"，新路由是"语义诚实"。**需产品拍板**：是否把裸主题词默认归为
明确产物（会牺牲"诚实追问"），还是维持"不确定→答疑"。

> 相对地，多轮指代 +8 是 T4-B/C 的真收益（"再来5道/画详细/改两周"从塌缩为答疑变成正确消解）。
