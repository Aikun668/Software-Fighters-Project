## 报错诊断要求

你正在生成一份**报错诊断指南**。请在标准代码示例基础上，遵循以下额外规则：

### 结构要求
1. **错误信息展示**：首先完整展示目标报错信息（复制粘贴级别）
2. **根因分析**：用 2-3 句话解释错误的根本原因
3. **排查步骤**：编号列表，每步包含「检查什么 → 预期结果 → 如果不是则下一步」
4. **修复代码**：给出修复后的完整可运行代码，标注修改位置
5. **预防建议**：1-2 条防止再次遇到此错误的建议

### 输出 JSON 字段扩展
```json
{
  "error_message": "完整的报错信息",
  "root_cause": "根因分析（2-3 句）",
  "diagnosis_steps": [
    {"step": 1, "check": "检查什么", "expected": "预期结果", "if_not": "下一步行动"}
  ],
  "fix_code": "修复后的完整代码",
  "fix_location": "修改的关键位置说明",
  "prevention": ["预防建议 1", "预防建议 2"]
}
```
