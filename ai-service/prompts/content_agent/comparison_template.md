## 对比分析要求

你正在生成一份**对比分析文档**。请在标准课程文档基础上，遵循以下额外规则：

### 结构要求
1. **并排对比表**：在概述之后插入 Markdown 对比表格，列出对比维度和双方特点
2. **对比维度至少包含**：核心思想、优缺点、适用场景、计算复杂度、代表性工作
3. **决策指南**：文末给出「什么时候选 A / 什么时候选 B」的实用建议

### 输出 JSON 字段扩展
在标准 outline 之外，额外包含：
```json
{
  "comparison_table": [
    {"dimension": "维度名", "side_a": "A 的特点", "side_b": "B 的特点"}
  ],
  "decision_guide": "基于场景的选择建议（2-3 句话）"
}
```
