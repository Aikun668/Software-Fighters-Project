# 过拟合、欠拟合与正则化：数学原理与实践

> 关联文档：02-machine-learning.md（机器学习基础）

## 核心问题：泛化

机器学习的终极目标不是让模型在训练集上表现完美，而是让模型对**未见过的新数据**也能做出准确预测，这种能力称为**泛化（Generalization）**。

泛化能力差的两种表现形式：过拟合与欠拟合。

---

## 过拟合与欠拟合的数学本质

### 偏差-方差分解（Bias-Variance Decomposition）

对于回归问题，期望泛化误差可以分解为：

$$\mathbb{E}[(y - \hat{f}(x))^2] = \underbrace{\text{Bias}[\hat{f}(x)]^2}_{\text{偏差}^2} + \underbrace{\text{Var}[\hat{f}(x)]}_{\text{方差}} + \underbrace{\sigma^2}_{\text{不可避免噪声}}$$

- **偏差（Bias）**：模型预测的期望值与真实值的偏离程度，反映模型对问题的**假设是否合理**。
- **方差（Variance）**：模型预测值随训练集变化的波动程度，反映模型对训练数据的**敏感程度**。
- **噪声（$\sigma^2$）**：数据本身的随机误差，任何模型都无法消除。

### 欠拟合（Underfitting）

**现象：** 训练误差高，验证误差也高。

**本质：** 高偏差（High Bias）。模型过于简单，无法捕捉数据的真实规律。

**例子：** 用一次线性函数拟合正弦曲线数据，模型假设空间太窄，天然无法表达弯曲的规律。

**解决方法：**
- 增加模型复杂度（更多参数、更深的网络）
- 增加特征数量
- 减少正则化强度

### 过拟合（Overfitting）

**现象：** 训练误差很低，但验证误差明显高于训练误差。

**本质：** 高方差（High Variance）。模型过于复杂，不仅学到了数据的真实规律，还"记住"了训练集中的噪声和偶然性，导致对新数据泛化能力差。

**例子：** 用10次多项式拟合10个数据点，多项式可以完美穿过每个点（训练误差为零），但在新数据上预测极不稳定。

## 正则化：从数学原理到实践

正则化（Regularization）通过在损失函数中加入惩罚项，约束模型参数的大小或稀疏性，以降低模型复杂度，提升泛化能力。

### L2 正则化（Ridge / 岭回归）

在原始损失函数 $L_0$ 的基础上加入参数的**平方和**惩罚：

$$L = L_0 + \frac{\lambda}{2} \sum_{j} w_j^2$$

其中 $\lambda$ 是正则化系数，控制惩罚力度。

**梯度更新推导：**

$$\frac{\partial L}{\partial w_j} = \frac{\partial L_0}{\partial w_j} + \lambda w_j$$

$$w_j \leftarrow w_j - \alpha \left(\frac{\partial L_0}{\partial w_j} + \lambda w_j\right) = (1 - \alpha\lambda)w_j - \alpha\frac{\partial L_0}{\partial w_j}$$

可以看到，L2正则化相当于每次更新前先将权重乘以一个小于1的系数 $(1-\alpha\lambda)$，称为**权重衰减（Weight Decay）**。权重永远被"拉向零"，但不会恰好等于零。

**特性：**
- 使所有参数均匀缩小，但保留所有特征的贡献
- 产生的是**稠密解**（所有参数都接近但不等于0）
- 对异常值（Outlier）有鲁棒性
- 等价于在参数上施加高斯先验（贝叶斯角度）

**几何理解：** L2正则化的约束区域是一个**球体**。损失函数的等高线与球体相切，切点通常不在坐标轴上，因此参数不会恰好为零。

### L1 正则化（Lasso）

加入参数的**绝对值之和**惩罚：

$$L = L_0 + \lambda \sum_{j} |w_j|$$

**梯度（次梯度）：**

$$\frac{\partial L}{\partial w_j} = \frac{\partial L_0}{\partial w_j} + \lambda \cdot \text{sign}(w_j)$$

其中 $\text{sign}(w_j)$ 为符号函数（正数取+1，负数取-1，零为0）。

**特性：**
- 倾向于产生**稀疏解**：许多参数会被精确压缩到零
- 具有**特征选择**效果：为零的权重意味着对应特征被完全忽略
- 等价于在参数上施加拉普拉斯先验（贝叶斯角度）

**几何理解：** L1正则化的约束区域是一个**菱形（Diamond）**，有尖锐的角落位于坐标轴上。损失函数等高线与菱形相切时，更容易恰好切在坐标轴上（即某个参数为零），这就是L1产生稀疏解的几何原因。

### L1 vs L2 关键对比

| 维度 | L1（Lasso） | L2（Ridge） |
|---|---|---|
| 惩罚项 | $\lambda\sum\|w_j\|$ | $\frac{\lambda}{2}\sum w_j^2$ |
| 解的稀疏性 | **稀疏**（部分参数为0） | **稠密**（参数接近但不为0） |
| 特征选择 | 自动（零权重=舍弃特征） | 不能（保留所有特征） |
| 约束区域几何形状 | 菱形（有尖角） | 球体（光滑） |
| 对异常值鲁棒性 | 较弱 | 较强 |
| 计算 | 需要次梯度，计算稍复杂 | 导数处处存在，计算简单 |
| 适用场景 | 特征维度高，真实特征稀疏 | 特征相关性强，希望保留所有特征 |

### Elastic Net（弹性网络）

L1和L2的线性组合，兼顾两者优点：

$$L = L_0 + \lambda_1 \sum_j |w_j| + \frac{\lambda_2}{2}\sum_j w_j^2$$

当特征之间存在强相关性时，L1倾向于随机选一个特征而丢弃其他，Elastic Net则能同时保留相关特征组。

## 其他常用正则化手段

### Dropout

神经网络专用正则化技术。训练时，以概率 $p$ 随机将部分神经元的输出置为零（关闭），测试时使用完整网络并将输出乘以 $(1-p)$（保持期望值不变）。

**直觉：** 迫使网络不能依赖任何单一神经元，学习更鲁棒的特征表示。等价于对网络结构做了随机集成。

**注意：** Dropout通常只在训练时使用，推理时必须关闭（`model.eval()`）。

### 早停（Early Stopping）

在训练过程中，持续监控验证集损失。当验证损失不再下降（或开始上升）时，停止训练，保存此时的参数。

本质上是利用验证集信号限制模型"记忆"训练集噪声的时间。

### 数据增强（Data Augmentation）

通过对训练样本施加随机变换（如图像的随机翻转、裁剪、旋转）来虚拟扩充训练集规模，是计算机视觉领域最常用的防过拟合手段。

## 交叉验证（Cross-Validation）

### K折交叉验证（K-Fold Cross-Validation）

**步骤：**
1. 将训练集随机分为K个大小相等的子集（Fold）
2. 进行K轮训练：第 $k$ 轮用第 $k$ 个子集作验证集，其余 $K-1$ 个子集合并作训练集
3. 得到K个验证误差，取平均值作为模型的泛化误差估计

$$CV_{error} = \frac{1}{K}\sum_{k=1}^{K} L_k$$

**作用：**
- 充分利用有限数据，每个样本都参与过验证
- 用于**模型选择**（比较不同算法）和**超参数调优**（如选择最优 $\lambda$）

**常用配置：** K=5 或 K=10 是工程实践中最常见的选择；当数据极少时，可用 K=N 的留一交叉验证（LOOCV）。

### 如何用交叉验证选择正则化系数 $\lambda$

```python
# 伪代码示意
lambdas = [0.001, 0.01, 0.1, 1.0, 10.0]
for lam in lambdas:
    cv_scores = []
    for k in range(K):
        # 划分第k折
        X_train_k, X_val_k = split(X, k)
        # 训练带正则化的模型
        model = train(X_train_k, lambda=lam)
        # 评估验证集误差
        cv_scores.append(evaluate(model, X_val_k))
    mean_error = mean(cv_scores)
# 选择mean_error最小对应的lambda
best_lambda = lambdas[argmin(mean_errors)]
```

## 常见误区

**误区1："训练集准确率越高越好"**
训练集准确率接近100%通常是过拟合的信号，关键指标是验证集/测试集的表现。

**误区2："正则化系数越大越好"**
$\lambda$ 过大会导致所有参数趋近于零，模型退化为常数预测，反而欠拟合。正则化强度需要通过交叉验证调整。

**误区3："Dropout可以用于所有层"**
输入层和输出层通常不使用Dropout，且Dropout概率对不同任务差异较大（一般0.3–0.5），需要调参。

---

## 总结

过拟合与欠拟合本质上是偏差-方差的权衡。正则化通过向损失函数施加参数惩罚来约束模型复杂度：L2产生稠密小权重，L1产生稀疏权重并实现特征选择，两者的几何本质决定了其行为差异。交叉验证是评估泛化能力和选择超参数的标准工程手段。
