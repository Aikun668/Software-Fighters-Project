# 梯度下降变体与优化算法

> 关联文档：02-machine-learning.md（机器学习基础）、06-backprop-derivation.md（反向传播推导）、code-01-gradient-descent.md（代码实现）

## 优化问题的本质

神经网络训练本质上是求解以下优化问题：

$$W^* = \arg\min_W L(W) = \arg\min_W \frac{1}{N}\sum_{i=1}^{N} \ell(f(x_i; W), y_i)$$

其中 $N$ 是训练样本总数，$\ell$ 是单样本损失，$f(x_i; W)$ 是模型预测。由于神经网络的损失曲面高度非凸，无法解析求解，必须依赖迭代优化。

梯度下降是最基础的迭代优化框架：沿当前参数处损失函数的梯度反方向移动一小步。

$$W \leftarrow W - \alpha \nabla_W L(W)$$

## 三种基础梯度下降变体

### 批量梯度下降（Batch Gradient Descent，BGD）

每次更新使用**全部** $N$ 个训练样本计算梯度：

$$\nabla_W L = \frac{1}{N}\sum_{i=1}^{N} \nabla_W \ell(f(x_i;W), y_i)$$

**优点：**
- 梯度估计准确，收敛曲线平滑
- 理论上保证收敛到（局部）最优解

**缺点：**
- 每次更新需遍历全部数据，计算成本极高
- 数据集无法放入内存时无法使用
- 参数更新频率低，训练慢

**适用场景：** 小数据集（几百到几千样本），或需要精确梯度的理论研究。

### 随机梯度下降（Stochastic Gradient Descent，SGD）

每次更新只随机选取**1个**样本计算梯度：

$$\nabla_W L \approx \nabla_W \ell(f(x_i;W), y_i), \quad i \sim \text{Uniform}(1, N)$$

**优点：**
- 每步计算量极小，更新频率高
- 随机性有助于跳出局部最优（鞍点）
- 适合在线学习（数据实时到来）

**缺点：**
- 梯度方差大，收敛曲线震荡剧烈
- 难以精确收敛，在最优点附近持续震荡
- 不能利用硬件并行计算优势

**噪声的双刃剑效应：** SGD 的随机梯度是真实梯度的有噪声估计，这种噪声在训练初期有助于探索损失曲面，但在训练后期又成为收敛的障碍。

### 小批量梯度下降（Mini-batch Gradient Descent）

每次更新随机选取 $B$ 个样本（Batch Size，通常32–512）：

$$\nabla_W L \approx \frac{1}{B}\sum_{i \in \mathcal{B}} \nabla_W \ell(f(x_i;W), y_i)$$

**优点：**
- 梯度估计比单样本更稳定，比全量计算更快
- 可充分利用GPU并行计算（矩阵批量运算）
- 灵活调节 Batch Size 以平衡速度与稳定性

**实践中的默认选择：** 现代深度学习几乎全部使用小批量梯度下降，通称"SGD"（语境中默认指小批量版本）。

**三种变体对比：**

| 维度 | BGD | SGD | Mini-batch SGD |
|---|---|---|---|
| 每步样本数 | 全部N | 1 | B（32-512） |
| 梯度估计质量 | 精确 | 高噪声 | 中等噪声 |
| 收敛稳定性 | 最稳定 | 震荡剧烈 | 较稳定 |
| 计算效率 | 低 | 高（但GPU利用率低） | 高（GPU利用率高） |
| 实际使用 | 极少 | 极少 | **主流** |

## 学习率的挑战

学习率 $\alpha$ 是梯度下降中最重要的超参数：

- **过大：** 参数更新步长太大，可能越过最优点，导致损失震荡甚至发散
- **过小：** 收敛极慢，可能陷入局部最优，训练时间过长
- **固定值的局限：** 训练初期希望大步探索，后期希望小步精调，固定学习率无法两全

**学习率调度（Learning Rate Scheduling）常用策略：**
- **Step Decay：** 每隔若干Epoch将学习率乘以衰减因子（如0.1）
- **余弦退火（Cosine Annealing）：** 学习率按余弦函数从初始值平滑衰减到接近0
- **Warmup：** 训练初期从极小的学习率逐步升到目标值，避免初期参数震荡

## 自适应优化算法

传统 SGD 对所有参数使用同一学习率，实践中效果不够理想。自适应优化算法为每个参数独立维护学习率，根据历史梯度信息自动调整。

### Momentum（动量）

引入"速度"概念，累积历史梯度方向，减少震荡，加速收敛：

$$v_t = \beta v_{t-1} + (1-\beta)\nabla_W L$$

$$W \leftarrow W - \alpha v_t$$

其中 $\beta$ 通常取0.9，表示历史速度的"记忆系数"。

**直觉：** 如同小球在碗里滚动，会积累惯性，在一致的梯度方向上加速，在震荡方向上相互抵消。

### RMSProp

对梯度的平方进行指数移动平均，自适应调整每个参数的学习率：

$$s_t = \rho s_{t-1} + (1-\rho)(\nabla_W L)^2$$

$$W \leftarrow W - \frac{\alpha}{\sqrt{s_t + \epsilon}} \nabla_W L$$

梯度历史较大的参数（波动剧烈）会获得较小的有效学习率，梯度历史较小的参数获得较大的有效学习率。$\epsilon$ 是防止除零的小常数（通常$10^{-8}$）。

### Adam（Adaptive Moment Estimation）

结合 Momentum（一阶矩）和 RMSProp（二阶矩），是目前深度学习中**最广泛使用**的优化器：

**维护两个移动平均：**

$$m_t = \beta_1 m_{t-1} + (1-\beta_1)\nabla_W L \quad \text{（一阶矩，梯度均值）}$$

$$v_t = \beta_2 v_{t-1} + (1-\beta_2)(\nabla_W L)^2 \quad \text{（二阶矩，梯度方差）}$$

**偏差修正（初始时矩估计偏向零）：**

$$\hat{m}_t = \frac{m_t}{1-\beta_1^t}, \quad \hat{v}_t = \frac{v_t}{1-\beta_2^t}$$

**参数更新：**

$$W \leftarrow W - \frac{\alpha}{\sqrt{\hat{v}_t} + \epsilon} \hat{m}_t$$

**默认超参数：** $\beta_1=0.9,\ \beta_2=0.999,\ \epsilon=10^{-8},\ \alpha=10^{-3}$。这组默认值在大多数任务上都能直接使用而无需调整，是 Adam 广受欢迎的主要原因。

**Adam 的局限：**
- 在某些任务上泛化性能不如精心调参的 SGD+Momentum
- 显存占用较高（需要维护两个与参数等量的状态向量）
- 在部分场景存在收敛到次优点的问题

### AdamW

Adam 的改进版本，将权重衰减（L2正则化）从梯度更新中分离，直接作用于参数：

$$W \leftarrow W - \frac{\alpha}{\sqrt{\hat{v}_t}+\epsilon}\hat{m}_t - \alpha\lambda W$$

分离的好处是避免自适应学习率对正则化效果的干扰，在大语言模型训练（BERT、GPT等）中是默认选择。

## 优化器对比总结

| 优化器 | 自适应学习率 | 动量 | 额外内存 | 适用场景 |
|---|---|---|---|---|
| SGD | 否 | 否 | 无 | 简单任务，理论研究 |
| SGD + Momentum | 否 | 是 | 1倍参数量 | CV任务，配合调参效果好 |
| RMSProp | 是 | 否 | 1倍参数量 | RNN、非平稳目标 |
| Adam | 是 | 是 | 2倍参数量 | **默认首选，大多数任务** |
| AdamW | 是（+正则分离） | 是 | 2倍参数量 | **预训练大模型** |

## 损失曲面的挑战

真实神经网络的损失曲面极为复杂，存在多种障碍：

**局部最优（Local Minima）：** 梯度为零但非全局最小值。实践研究表明，大型网络的局部最优通常损失值与全局最优接近，影响有限。

**鞍点（Saddle Point）：** 某些方向是极小值，另一些方向是极大值。在高维空间中，鞍点比局部最优更常见，是训练停滞的主要原因。SGD 的随机性有助于逃离鞍点。

**平坦区域（Plateau）：** 梯度接近零但未到达最优，导致训练进展极慢。

**悬崖（Cliff）：** 损失曲面某处梯度突然极大，导致参数更新幅度异常，可用梯度裁剪（Gradient Clipping）处理：

$$\text{if } \|\nabla_W L\| > \text{threshold}: \quad \nabla_W L \leftarrow \frac{\text{threshold}}{\|\nabla_W L\|}\nabla_W L$$

## 总结

梯度下降从全量批次到单样本，再到小批量，在计算效率与梯度质量之间折中。自适应优化算法（Adam、AdamW）通过维护梯度的一阶、二阶矩为每个参数独立调整学习率，是现代深度学习的默认优化工具。理解各变体的数学原理，有助于在实际任务中做出合理的优化器选择和超参数配置。
