**Java 后续动作**：拿回 questions → 存入练习库 → 前端展示 → 用户答题 → grade → analyze → 更新图谱。

## 三、数据流：完整的「学习→练习→图谱」闭环

```
学生制定计划
  → POST /plans/create-from-path
  → Java 存 plan（含 milestones + steps[].knowledge_node_id）

学生按计划学习
  → 每完成一个 step，前端点「完成学习」
  → Java 调 POST /plans/{id}/complete-step
  → Python 返回巩固题（带 knowledge_node_id）
  → Java 存题到练习库
  → 前端展示题目
  → 用户答题
  → Java 调 POST /exercise/grade（choice/short_answer/code）
  → Java 调 POST /exercise/session/analyze
  → Java 透传 mastery_events → POST /graph/masteries
  → 图谱变色 ✅

学生荒废几天后回来
  → Java 调 POST /plans/{id}/status
  → Python 计算 soft_landing + decay + milestone_progress
  → 若 days_idle > 7，前端引导进入回归检测
  → Java 调 POST /plans/{id}/regression-check
  → Python 出热身题 → 判分 → 重排计划
```

## 五、新增端点（2026-06-15 第二轮）

### 5.1 `POST /plans/{plan_id}/today`（新增）

获取今日应完成的学习步骤 + 资源建议。

```
请求：
{
  "plan": {"id": 1, "total_steps": 14, "completed_steps": 3, "start_date": "2026-06-01", "milestones": [...]},
  "steps": [...],                           // 全部步骤
  "start_date": "2026-06-01",               // 可选，缺省用 plan.start_date
  "masteries": {"backpropagation": 0.65}    // 可选，当前各节点掌握度
}

响应：
{
  "code": 0,
  "data": {
    "plan_id": 1,
    "today": "2026-06-15",
    "day_index": 14,
    "total_days_elapsed": 15,
    "steps_due_today": [
      {
        "step_order": 5,
        "topic": "反向传播",
        "knowledge_node_id": "backpropagation",
        "status": "pending",
        "estimated_days": 3,
        "topic_difficulty": 4,
        "suggested_resource_types": ["document", "code_demo", "exercise", "mindmap"],
        "day_progress": 2,                    // 今天是该 step 的第 2/3 天
        "day_total": 3,
        "current_mastery": 0.65
      }
    ],
    "resource_suggestions": [
      {
        "step_order": 5,
        "topic": "反向传播",
        "knowledge_node_id": "backpropagation",
        "resource_types": ["document", "code_demo", "exercise", "mindmap"],
        "gen_prompt": "请为「反向传播」生成学习资源，难度等级 4/5"
      }
    ],
    "next_milestone": {
      "milestone_id": "m1",
      "description": "理论基础建立",
      "after_step": 5,
      "steps_remaining": 2
    },
    "summary": "今日有 2 个学习步骤"
  }
}
```

**Java 动作**：拿到 `steps_due_today` → 展示今日任务列表 → 用户点击某个 step 时，用 `resource_suggestions[].gen_prompt` 调 `/resources/generate` 生成学习资料。

**计算逻辑**：
- 从 `start_date` 起，按每个 step 的 `estimated_days` 累计计算每天的步骤区间
- 当天落在哪个步骤的区间内，就返回哪些步骤
- 若计划进度落后（当天无步骤但还有未完成步骤），返回下一个待完成步骤并附带 `note`

### 5.2 `POST /plans/{plan_id}/progress`（新增）

更新步骤学习进度，计算掌握度变化。匹配前端对接文档 3.5 节规范。

```
请求：
{
  "user_id": 1,
  "step_id": 5,                              // 步骤 ID（优先）
  "step_order": 3,                           // 步骤序号（step_id=0 时使用）
  "status": "completed",                     // completed / in_progress / paused / review
  "score": 0.8,                              // 练习得分 0-1（可选）
  "activity_type": "exercise",               // study / exercise / quiz / review
  "duration_minutes": 25,
  "plan": {"id": 1, "total_steps": 14, ...},
  "steps": [...],                            // 全部步骤列表
  "masteries": {"gradient_descent": 0.6}     // 当前各节点掌握度
}

响应：
{
  "code": 0,
  "data": {
    "plan_id": 1,
    "updated_step": {
      "step_order": 3,
      "topic": "梯度下降",
      "knowledge_node_id": "gradient_descent",
      "status": "completed",
      "score": 0.8,
      "mastery_current": 0.68,
      "activity_type": "exercise",
      "duration_minutes": 25
    },
    "mastery_updates": {
      "gradient_descent": {
        "old_mastery": 0.6,
        "new_mastery": 0.68,
        "delta": 0.08,
        "event_type": "exercise_done"
      }
    },
    "completed_steps": 3,
    "total_steps": 14,
    "progress_pct": 21,
    "next_milestone": {...},
    "updated_steps": [...]                   // 更新后的完整步骤列表
  }
}
```

**Java 动作**：
1. 拿到 `mastery_updates` → 调 `POST /graph/masteries` 更新图谱节点掌握度
2. 拿到 `updated_steps` → 更新数据库中的 plan steps 状态
3. 进度条更新为 `progress_pct`%

**步骤定位规则**：`step_id > 0` 时按 id 匹配，否则按 `step_order` 匹配。两者均不匹配返回 404。

### 5.3 `POST /plans/{plan_id}/node-status-change`（新增）

知识图谱节点状态变化 → 计划联动。Java 在节点 mastered/forgotten/learning/locked 时调用。

```
请求：
{
  "node_id": "backpropagation",
  "old_status": "learning",
  "new_status": "mastered",
  "plan": {"id": 1, ...},
  "steps": [...],
  "masteries": {"backpropagation": 0.9}
}

响应：
{
  "code": 0,
  "data": {
    "plan_id": 1,
    "node_id": "backpropagation",
    "new_status": "mastered",
    "affected_steps_count": 1,
    "plan_actions": [
      {
        "step_order": 5,
        "topic": "反向传播",
        "action": "mark_completed",
        "old_status": "in_progress",
        "new_status": "completed",
        "message": "步骤「反向传播」对应节点已掌握，建议标记为完成"
      }
    ],
    "updated_steps": [...],
    "plan_status": "active",
    "completed_steps": 4,
    "total_steps": 14,
    "progress_pct": 29,
    "next_milestone": {...},
    "summary": "节点状态变更影响 1 个计划步骤"
  }
}
```

**4 种联动场景**：

| new_status | plan_action | 说明 |
|-----------|-------------|------|
| `mastered` | `mark_completed` | 节点已掌握 → 对应步骤标为完成 |
| `forgotten` | `schedule_review` | 节点遗忘 → 步骤标为 review + 计算 decayed_mastery |
| `learning` | `unlock_step` | 前置条件满足 → locked→pending |
| `locked` | `lock_step` | 前置条件丢失 → pending→locked |

**Java 动作**：
1. 遍历 `plan_actions`，按 `action` 类型更新对应步骤状态
2. 若 `plan_status` 变为 `completed`，更新计划整体状态
3. 用 `updated_steps` 全量覆盖数据库中的步骤列表

## 六、create-from-path 新增字段


**资源类型映射规则**（按知识点分类）：

| 应用/实战 | document, case_study, code_demo, exercise |

| 其他 | document, mindmap, exercise |

**Java 动作**：创建 plan 时存入 `suggested_resource_types`，前端展示步骤卡片时据此渲染资源入口按钮。
