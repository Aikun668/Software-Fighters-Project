# 用户功能全景图：我是一个学生，我怎么用这个AI教育系统？

> **阅读方式**: 先宏观了解"我能做什么"，再看"系统怎么满足我"。
> **定位**: 本文档从终端用户视角描述功能，不涉及技术实现细节。

## 一、宏观视角：我是一个学生，打开这个系统，我能干几件大事？

你是一个想学人工智能的大学生，打开"Software-Fighters AI导师"系统，你会发现**5大核心功能区**：

```
┌─────────────────────────────────────────────────────────────┐
│                    AI 智能辅导系统                            │
├─────────────┬─────────────┬─────────────┬───────────────────┤
│  🤖 AI答疑   │  📊 画像构建  │  📚 资源生成  │  🎯 练习题        │  🗺️ 学习路径 │
├─────────────┼─────────────┼─────────────┼───────────────────┤
│ 问任何问题  │ 聊天了解你   │ 生成专属    │ 针对性出题       │ 规划学习     │

**一句话总结**: 系统通过跟你聊天了解你，然后给你**量身定做**学习内容、练习题和学习计划。

## 二、逐个拆解：每个功能我具体怎么操作？系统怎么回应？

### 功能1：AI智能答疑（最常用）

**场景**: 你在学CNN，不懂"卷积"是什么意思

**你做的事**:
1. 打开"AI答疑"页面
2. 在输入框打字："CNN里的卷积到底是什么？"
3. 按回车

**你看到什么**:
- 屏幕开始出现"打字机效果"，AI一个字一个字回答你
- 回答里可能包含：
  - 通俗解释（"就像一个滤镜在图片上滑动..."）
  - 数学公式（LaTeX渲染）
  - 代码示例（Python高亮）
  - 相关知识点链接

**系统背后怎么做的**:
```
你的问题 "CNN里的卷积到底是什么？"
    ↓
[TutorAgent] 接收到问题
    ↓
[检索知识库] 去ChromaDB查 "卷积神经网络"、"卷积操作" 相关文档
    ↓
[读取你的画像] 发现你"数学基础薄弱"
    ↓
[生成回答] 少讲数学公式，多打比方、给可视化解释
    ↓
[SSE流式返回] 你看到一个字一个字跳出来
```

**关键点**: 
- 不是简单的搜索引擎，而是**结合你的弱项**个性化回答
- 如果你数学好，回答会更公式化；如果你数学差，回答会更形象

### 功能2：学生画像构建（第一次用系统时）

**场景**: 你第一次注册登录，系统要了解你

**你做的事**:
1. 进入"个人画像"页面
2. 系统弹出聊天框："你好！我是你的AI学习助手。想了解一下你的学习背景~"
3. 你回复："我是计算机专业大二学生，编程还行，但高数一直不太好"
4. 系统继续问："你对AI的哪个方向比较感兴趣？比如图像识别、自然语言处理？"
5. 你回复："我对图像识别比较感兴趣，想做人脸识别相关的"
6. 系统再问："你每周能投入多少时间学习？"
7. 你回复："大概每天1-2小时吧"

**你看到什么**:
- 一个友好的聊天界面，像跟朋友聊天
- 聊完后，你的"个人档案"自动填满了：
  - ✅ 知识基础：中等（70分）
  - ✅ 认知风格：视觉型（你喜欢看图、视频）
  - ✅ 学习目标：掌握计算机视觉、做人脸识别项目
  - ✅ 薄弱点：数学（高数不好）
  - ✅ 学习节奏：中等（每天1-2小时）
  - ✅ 兴趣方向：CV（计算机视觉）

**系统背后怎么做的**:
```
你说的每一句话
    ↓
[ProfileAgent] 分析你的回答
    ↓
提取关键信息："编程还行"→知识基础=70; "高数不好"→薄弱点=[数学]
    ↓
[存储画像] 自动保存到数据库
    ↓
[判断完整度] 6个维度都填满了？→ 画像完成！
    ↓
[影响后续所有功能] 以后TutorAgent、ContentAgent都会读这个画像
```

**关键点**:
- 不是填表格，是**自然对话**！你说什么，AI自己提炼
- 画像越完整，后面的推荐越精准
- 可以随时回来修改/补充

### 功能3：学习资源生成（生成专属教材）

**场景**: 你要学"卷积神经网络"，想要一份专属学习材料

**你做的事**:
1. 进入"资源生成"页面
2. 输入主题："卷积神经网络"
3. 点击"生成专属资料"
4. 等待几秒（看到进度条）

**你看到什么**:
系统生成一份**结构化学习文档**，包含：

```

📌 第1部分：什么是卷积？（针对你的水平调整）
   因为你数学薄弱，这里用"滤镜滑动"比喻，
   而不是直接扔公式

━━━━━━━━━━━━━━━━━━━━━━
💻 第2部分：PyTorch代码示例
   ```python
   import torch.nn as nn
   conv = nn.Conv2d(1, 32, kernel_size=3)
   ```
   [可点击"运行"看结果]

━━━━━━━━━━━━━━━━━━━━━━
⚠️ 第3部分：常见坑点
   - 卷积核大小选多少？
   - Padding怎么设？
   - 输出尺寸怎么算？

━━━━━━━━━━━━━━━━━━━━━━
🧠 第4部分：思维导图
   [一张可交互的知识图谱，显示：]
   卷积神经网络
     ├── 卷积层 ←→ 池化层
     ├── 激活函数
     └── 全连接层

━━━━━━━━━━━━━━━━━━━━━━
📝 配套练习题（3道）
   1. 【选择题】卷积操作的主要作用是？
      A. 降维  B. 特征提取  C. ...
   
   2. 【填空题】Conv2d的参数分别是...?
   
   3. 【编程题】用PyTorch写一个简单CNN...
```

**系统背后怎么做的**:
```
你输入"卷积神经网络"
    ↓
[ContentAgent] 生成大纲（根据你的画像调整深度）
    ↓
[ContentAgent] 逐块生成内容
  - section: 文字讲解（避开数学，因为你数学弱）
  - code: PyTorch代码（因为你编程还行）
  - callout: 重点提示
    ↓
[ExerciseAgent] 生成3道配套练习题
  - 第1题考概念（简单）
  - 第2题考细节（中等）
  - 第3题编程实践（因为你编程好）
    ↓
[MindMapAgent] 生成知识图谱JSON
    ↓
[SSE流返回] 你看到一个块一个块出现
```

**关键点**:
- 不是去网上搜资料，是**AI现场给你写一份**
- 内容**根据你的画像定制**：数学弱的少公式，编程好的多代码
- 一次生成 = 文字 + 代码 + 思维导图 + 练习题，完整闭环

## 五、系统的"智能"体现在哪里？（用户感知）

作为一个用户，你会觉得系统"懂我"，因为：

### 1. 回答因人而异
- **你问**: "什么是梯度下降？"
- **如果你数学好**: 回答会讲偏导数、链式法则、学习率的数学意义
- **如果你数学差**: 回答会用"下山找最低点"的比喻，配动画

### 2. 出题因人而异
- **同一个知识点**：CNN
- **如果你编程好**: 编程题让你写完整网络
- **如果你编程弱**: 编程题只让你填关键参数

### 3. 学习路径因人而异
- **同目标**：学CV
- **如果你基础好**: 路径短，跳过基础
- **如果你基础弱**: 路径长，插入补习

### 4. 持续进化
- 你每做一道题、每问一个问题，系统都在默默更新你的画像
- 一个月后，系统比你自己还清楚你哪里会、哪里不会

## 六、边界说明：系统**不能**做什么？（管理用户预期）

| 用户期望 | 系统实际能力 | 建议 |
|----------|-------------|------|
| "帮我写毕业论文" | ❌ 不能。系统只辅助学习，不代写 | 可以问"论文里的CNN部分怎么写" |
| "替我考试" | ❌ 不能。系统不出真实考题 | 可以用练习题自测 |
| "实时视频讲解" | ❌ 不能。只有文字+代码+静态图 | 文字足够详细，代码可运行 |
| "一对一真人辅导" | ❌ 不能。是AI，不是真人 | 但AI 24小时在线，响应快 |
| "自动帮我学" | ❌ 不能。系统给材料，但要你自己看 | 降低认知负荷，但不替代努力 |
| "保证我学会" | ❌ 不能。学习效果取决于你的投入 | 系统提供最优路径和材料 |

## 七、总结：用户视角的一句话

> "这是一个**懂你的AI学习伙伴**：你先跟它聊聊天让它了解你，然后它会给你**量身定做**学习材料、出题考你、规划路线。你随时有问题问它，它的回答会根据你的基础自动调整难度。"

**核心体验**: 
- **输入**: 自然语言（聊天、提问）
- **输出**: 个性化内容（文字、代码、图表、题目）
- **机制**: 多Agent协作 + 画像驱动 + RAG知识库
