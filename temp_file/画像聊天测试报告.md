# 画像聊天模块测试报告

## 测试概述
- **测试时间**: 2026-06-10
- **测试场景**: 4个（零基础、有经验、模糊用户、研究生）
- **每场景轮次**: 4-9轮
- **LLM**: DeepSeek-v4-flash (OpenAI兼容)
- **提取模型**: temperature=0.3
- **回复模型**: temperature=0.7

## 测试结果汇总

| 场景 | 描述 | 轮次 | 完整度 | 缺失维度 |
|------|------|------|--------|----------|

| B | 有经验学生 | 5 | 6/6 | 无 |
| C | 模糊用户 | 4 | 3/6 | knowledge_base, cognitive_style, learning_pace |
| D | 研究生 | 9 | 6/6 | 无 |

## 增量更新分析

### 1. 状态流转正常
- **extract → merge → director → response/complete** 流程运转正常
- profile_changed 标志位正确触发
- last_extracted_msg_index 正确递增

### 2. 条目状态问题
- **所有 entries 状态为 tentative**（从未提升到 active）
- **原因**: AUDIT_INTERVAL=10，但测试轮次最多9轮，未达到触发阈值
- **建议**: 降低 AUDIT_INTERVAL 到 5-7轮，或在画像完整时主动触发一次audit

### 3. Stability Counter 行为
- STABILITY_N=1 后，值立即应用，count重置为0
- **副作用**: 无法观察稳定性历史
- **建议**: STABILITY_N=1 适合比赛演示，但生产环境建议=2

### 4. 认知风格振荡
- **Scene B 第2轮**: cognitive_style → kinesthetic（基于"做过项目"推断）
- **Scene B 第4轮**: cognitive_style → theoretical（基于"先理解原理"修正）
- **结论**: 系统能根据新信息修正之前的推断，符合预期

## 发现的问题

### P0 - 高优先级

1. **entries 全部为 tentative**
   - 影响: 画像可信度标识未生效
   - 修复: 降低 AUDIT_INTERVAL 或在 complete 时触发 audit

2. **stability_counter count 始终为0**
   - 影响: 无法追踪信息稳定性历史
   - 原因: STABILITY_N=1 时值立即应用并清零
   - 建议: 生产环境恢复为2，演示环境保持1

### P1 - 中优先级

3. **learning_pace 提取不够精细**
   - "每周20小时"被归类为 fast/steady/slow 之一
   - 建议: 保留原始描述或增加具体数值维度

4. **interest_direction 条目去重不足**
   - "深度学习"和"图像分类"在语义上有重叠
   - 建议: 增加语义相似度去重

### P2 - 低优先级

5. **Scene C 提取率低**
   - 用户输入模糊时仅提取3/6维度
   - 这是预期行为，但AI追问可以更针对性

6. **knowledge_base 评分波动**
   - Scene B: 30 → 36（合理微调）
   - Scene A: 0 → 6 → null（应保持稳定）

## 优化建议

### 即时修复（今天可做）
1. 降低 AUDIT_INTERVAL = 5（原10）
2. 在 _complete_node 中触发一次 audit
3. 修复 knowledge_base 评分不应回退的问题

### 短期优化（本周）
1. 增加 learning_pace 的数值保留（如"每周20小时"）
2. interest_direction 增加语义去重
3. 优化 extract prompt，提升 learning_pace 提取率

### 中期优化（比赛前）
1. 增加 few-shot 示例到 extract prompt
2. 实现 entries 的主动晋升机制（用户确认后）
3. 增加画像可视化展示给用户的逻辑
