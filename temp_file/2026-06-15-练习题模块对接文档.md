## 二、端点契约详表

### 2.1 `POST /exercise/categorize`

题目打标 —— 用户从聊天中「加入练习」后，Java 需要知道每道题属于哪个知识图谱节点。

```
请求：
{
  "exercises": [
    {
      "question": "什么是反向传播？",
      "answer": "通过链式法则计算神经网络中每一层梯度的算法",
      "question_type": "short_answer",
      "options": {},
      "source": "chat"
    }
  ],
  "course_id": "ai_intro",
  "knowledge_nodes": [
    {"id": "backpropagation", "name": "反向传播", "description": "..."},
    {"id": "gradient_descent", "name": "梯度下降", "description": "..."}
  ]
}

响应：
{
  "code": 0,
  "data": {
    "results": [
      {
        "index": 0,
        "knowledge_node_id": "backpropagation",
        "difficulty": 3,
        "question_type": "short_answer",
        "confidence": 0.95
      }
    ]
  }
}
```

**Java 调用流程**：
1. 用户聊天中点「加入练习」→ 前端传题目文本到 Java
2. Java 调 `POST /graph/layered` 获取当前所有节点 → 得到 knowledge_nodes
3. Java 调 `POST /exercise/categorize` 传入题目 + 节点列表
4. 拿回 `knowledge_node_id`，将题目 + 标签存入练习库

### 2.2 `POST /exercise/session/analyze`

练习会话分析 —— 用户做完一批题后分析表现。

```
请求：
{
  "records": [
    {
      "knowledge_node_id": "backpropagation",
      "question": "反向传播中梯度消失的原因是？",
      "question_type": "choice",
      "user_answer": "A",
      "correct_answer": "B",
      "is_correct": false,
      "time_spent_seconds": 45,
      "difficulty": 3
    }
  ],
  "course_id": "ai_intro",
  "masteries": {"backpropagation": 0.5, "gradient_descent": 0.7}
}

响应：
{
  "code": 0,
  "data": {
    "overall_score": 60,
    "total_questions": 5,
    "correct_count": 3,
    "accuracy_pct": 60,
    "per_node": [{
      "knowledge_node_id": "backpropagation",
      "accuracy": 50,
      "total": 2,
      "correct": 1,
      "avg_difficulty": 2.5,
      "current_mastery": 0.5
    }],
    "weak_nodes": [{"knowledge_node_id": "backpropagation", "current_mastery": 0.5}],
    "strengths": [{"knowledge_node_id": "gradient_descent"}],
    "suggestions": ["建议针对薄弱模块进行针对性练习", "薄弱知识点: backpropagation"],
    "mastery_updates": [{
      "knowledge_node_id": "backpropagation",
      "old_mastery": 0.5,
      "new_mastery": 0.38
    }],
    "mastery_events": [
      {"node_id": "backpropagation", "event_type": "exercise_done", "score": 0.8},
      {"node_id": "backpropagation", "event_type": "exercise_failed"}
    ]
  }
}
```

**mastery_events 的关键用途**：这个数组的格式与 `POST /graph/masteries` 的 `events` 字段完全一致，Java 可以直接透传：

```java
// Java 端：analyze 返回后直接更新图谱
var analysis = pythonClient.post("/exercise/session/analyze", request);
var events = analysis.get("data").get("mastery_events");
pythonClient.post("/graph/masteries", Map.of(
    "course_id", courseId,
    "masteries", currentMasteries,
    "events", events  // ← 直接透传
));
```

### 2.5 `POST /exercise/generate`（增强：`knowledge_node_id` + `strategy` + `code` 题型）

```
请求示例——从图谱节点进入（不传 topic，node_id 优先）：
{
  "knowledge_node_id": "backprop",
  "strategy": "weakness",
  "count": 5,
  "difficulty": "medium",
  "student_profile": {...},
  "user_id": 123
}

strategy 行为说明：
  "weakness" → 侧重薄弱子概念，难度降为 easy，题目生成时加针对性提示词
  "review"   → 生成与常见错题同类但不同问法的变体题
  "new"      → 默认行为，生成全新题目

响应（SSE 流，最终 DONE 事件含 questions 数组）：
{
  "type": "done",
  "questions": [
    {
      "question_type": "code",
      "question": "请编写代码实现反向传播的核心逻辑...",
      "options": null,
      "correct_answer": "def backward(...)...",
      "explanation": "代码需要正确实现...",
      "topic": "backpropagation",
      "knowledge_node_id": "backprop"        // ← 每题自动带锚点
    },
    {
      "question_type": "choice",
      "question": "反向传播中梯度消失的原因是？",
      "options": {"A": "...", "B": "...", "C": "...", "D": "..."},
      "correct_answer": "B",
      "explanation": "激活函数导数连乘后趋近于零",
      "topic": "backpropagation",
      "knowledge_node_id": "backprop"        // ← 每题自动带锚点
    }
  ]
}

注意：knowledge_node_id 传入后 Python 端自动根据它推断 topic，
      无需 Java 额外查节点信息。每题生成后自动打 knowledge_node_id 标签。
```

### 2.6 `POST /exercise/grade`（增强：支持 `code` 题型）

```
请求（choice 示例）：
{
  "type": "choice",
  "user_answer": "B",
  "correct_answer": "B",
  "choices": ["A.xxx", "B.xxx", "C.xxx", "D.xxx"],
  "multi": false,
  "points": 5
}

请求（short_answer 示例）：
{
  "type": "short_answer",
  "user_answer": "反向传播是通过链式法则...",
  "reference_answer": "反向传播是计算神经网络梯度的算法",
  "rubric": "准确描述核心原理 60分，提及链式法则 +20分，举例 +20分"
}

请求（code 示例）：
{
  "type": "code",
  "user_answer": "def backward(x):\n    return x * (1 - x)",
  "reference_answer": "def sigmoid_derivative(x):\n    s = 1/(1+math.exp(-x))\n    return s * (1 - s)",
  "rubric": "函数签名正确 20分，公式正确 50分，边界处理 30分"
}

响应（code 题型）：
{
  "code": 0,
  "data": {
    "type": "code",
    "score": 60,
    "earned": 60,
    "max_score": 100,
    "correct": true,
    "syntax_ok": true,          // ← code 题型特有字段
    "logic_ok": true,           // ←
    "edge_cases_ok": false,     // ←
    "feedback": "公式基本正确，但未处理 x 过大时的溢出问题",
    "ai_comment": "公式基本正确..."
  }
}

Java 调用注意：
  - choice 题型：Java 可本地判分（精确匹配），也可调 Python（返回更丰富的 feedback）
  - short_answer 题型：必须调 Python（LLM 判分）
  - code 题型：必须调 Python（三维 LLM 判分）
```

## 五、关键注意事项

1. **`mastery_events` 透传**：`analyze_session` 返回的 `mastery_events` 数组中每个元素格式为 `{node_id, event_type, score?}`，与 `MasteryEvent` Pydantic 模型完全对齐，Java 无需做任何字段转换，直接放入 `POST /graph/masteries` 的 `events` 数组。

2. **categorize 需要节点列表**：调 `/exercise/categorize` 前先调 `POST /graph/layered` 拿 `nodes[]`，提取每个节点的 `id/name/description` 三个字段传过去即可。

3. **`knowledge_node_id` 是全局键**：练习模块的所有分析都依赖这个字段。确保 Java 侧练习库表有索引、落库时必填。

4. **code 判分返回三维指标**：`grade_code` 返回 `syntax_ok` / `logic_ok` / `edge_cases_ok` 三个布尔值，前端可分别展示语法/逻辑/边界通过状态。`score >= 60` 即 `correct: true`。

5. **错题查询不归 Python 管**：错题列表是纯 DB 查询（`WHERE is_correct = false`），Java 直接查 SQL 返回给前端，无需经 Python。Python 只做归因分析（已有 `POST /exercise/error-analysis`）。
