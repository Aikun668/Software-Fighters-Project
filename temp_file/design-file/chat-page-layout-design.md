## 一、页面在系统中的位置

```
┌──────────────────────────────────────────────────────────────┐
│  Header（固定顶部 60px）                                      │
├────────┬─────────────────────────────────────────────────────┤
│        │                                                     │
│ Sidebar│            对话辅导页（本文件）                       │
│ (已设计)│            router-view 渲染                        │
│        │                                                     │
│        │                                                     │
└────────┴─────────────────────────────────────────────────────┘
```

**路由**：`/question-nav-chat?conversationId=xxx`

**与 Sidebar 的关系**：
- 侧边栏的对话记录列表控制当前对话的切换
- 本页不包含对话历史列表（已移至 Sidebar）
- 本页接收 `conversationId` 参数加载对应对话

### 3.2 欢迎问候语

**位置**：消息区域垂直居中偏上（约 35% 位置）

**规则**：
- 纯文字，无图标，无标题
- 字体大小：16px
- 每次进入空状态时从词库随机抽取一句
- 词库内容：

```
"今天想探索什么知识？"
"准备好学点新东西了吗？"
"有什么问题，随时问我。"
"今天的学习计划是什么？"
"想深入了解哪个方向？"
"来，一起解决难题。"
"哪里卡住了？我帮你理一理。"
"今天状态怎么样？聊聊学习？"
"有段时间没复习了，想从哪里开始？"
"来吧，什么都可以问。"
"想刷几道题热热身吗？"
"有什么概念一直没弄明白的？"
```

> **【待确认 ①】** 词库是否需要增减？是否按时间段变化（如早上/晚上不同问候）？

### 3.3 快捷卡片区

**布局**：5 张卡片，第一行 3 张，第二行 2 张（居中）

**单张卡片规格**：

```
┌─────────────────────┐
│ 🤖                   │  ← emoji 左上角
│ 自动                 │  ← 模式名
│                      │  ← gap: 8px
│ xxx的xxx是xxx        │  ← 示例文字（随机抽取）

宽度：约 180px（自适应）
高度：约 100px

**5 张卡片与词库**：

**随机规则**：

- 词库每条被抽中概率相等

**卡片交互**：
- hover：上浮 2px
- 点击：① 切换到该卡片对应的 mode  ② 示例文字填入输入框  ③ **不自动发送，等用户确认/修改后手动按 Enter**

#### 4.3.3 消息头细节

```
AI助手  [模式标签]  [🦉 苏格拉底]  14:31
──────  ──────────  ─────────────  ─────
发送者   当前模式     style 标签     时间

模式标签：小圆角矩形，显示当前使用的 mode（自动/出题练习/资源生成/学习路径/可视化）

时间：消息发送/接收时的 HH:MM
```

> **【注意】** 苏格拉底引导模式下，消息头只显示 `[🦉 苏格拉底]`，**不显示** "第x轮" 轮次计数。轮次信息仅为后端逻辑，对用户无意义。

## 五、输入区域

### 5.1 结构

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│  ┌──────────────────────────────────────────────┐   │
│  │ 📝 输入你的问题...                        📎  │   │
│  │                                              │   │
│  └──────────────────────────────────────────────┘   │
│                                                      │
│  [模式选择器 ▾]  [讲解风格 ▾]              🔗  ⏫   │
│                                                      │
│  按 Enter 发送  ·  Shift+Enter 换行                  │
└──────────────────────────────────────────────────────┘

textarea：自适应高度，最小 1 行，最大 6 行
Placeholder 随模式变化（见 5.2）
📎：文件上传按钮（预留，当前可先隐藏或禁用）
🔗：关联上下文（从知识图谱绑定知识点，预留）
⏫：发送按钮（有文字时高亮可用，无文字时灰态禁用）
    流式输出中变为 ⏹（停止生成按钮）
全局 padding：12px
```

### 5.2 Placeholder 随模式切换

| 模式 | placeholder 文字 |
|------|-----------------|
| 自动 | "输入你的问题..." |
| 出题练习 | "输入知识点，我为你出题..." |
| 资源生成 | "输入主题，我生成学习资料..." |
| 学习路径 | "描述学习目标，我规划路线..." |
| 可视化 | "输入要可视化的概念或结构..." |

### 5.3 键盘交互

| 操作 | 行为 |
|------|------|
| Enter | 发送消息（输入框非空时） |
| Shift + Enter | 换行 |
| 输入框为空 + Enter | 无反应 |
| 流式输出中 + Enter | 无反应（发送按钮已变为停止按钮） |

| 前端选项 | 发送的 mode 参数 | 发送的 style 参数 |

| 出题练习 | `exercise` | 不传 |
| 资源生成 | `resource` | 不传 |
| 学习路径 | `plan` | 不传 |
| 可视化 | `visualization` | 不传 |

### 6.4 切换模式时的联动

```
切换模式 →

  ② 讲解风格选择器显示/隐藏
  ③ 如果从「自动+苏格拉底」切换到其他模式：
     style 重置为 standard
```

### 8.2 发送消息全流程

```
用户输入文字 → 选择模式/风格 → 按 Enter
       │
       ▼
┌─────────────────┐
│ 用户消息气泡     │  右对齐，即时显示
│ 添加到消息列表   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐

│ streaming=true   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 调用 SSE API     │  POST /api/chat
│ mode + style     │  body: { message, mode, style, conversation_id }
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ SSE 逐字流式输出  │  onData(delta, mode)

└────────┬────────┘
         │
         ▼
