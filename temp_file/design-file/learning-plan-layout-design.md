## 一、设计原则

```
长期计划 + 每日拆解 + 外科手术式动态调整
─────────────────────────────────────────
· 一个计划 = 大模块 → 子模块 两级粒度
· 多个长期计划并存
· 每日自动生成今日计划（合并所有长期计划的任务）
· 只调整受影响的依赖链，不牵一发而动全身
· 三层（计划 / 大模块 / 子模块）全部可手动编辑
· 通过对话或 AI 按钮触发智能调整
```

**今日计划生成逻辑**：

```
每天首次打开页面 → 自动调用今日计划 Agent：

输入：
  · 用户所有活跃计划的所有未完成模块
  · 各模块当前 mastery / 进度
  · 昨日今日计划的完成情况
  · 半衰期复习提醒（哪些知识点该复习了）
  · 默认容量：每天 2h

输出：4~8 条今日任务
  每条：任务名 + 类型 + 预估时长 + 来源模块

优先策略：
  1. 优先安排半衰期到期需复习的模块
  2. 其次安排当前正在进行的模块
  3. 同一模块的子任务尽量连续排列
  4. 任务时长总和控制在 2h 以内

合并规则：
  多个计划的任务合并到同一份今日计划
  每条任务标注来源计划/模块
```

**昨日未完成处理**：


### 4.4 三级编辑能力

| 层级 | 可操作项 |
|------|---------|
| **计划** | 重命名 / 删除 / AI 调整 / 新建 |
| **大模块** | 重命名 / 删除 / 跳过 / 拖拽排序 / 添加子模块 / AI 调整此模块 |
| **子模块** | 重命名 / 删除 / 关联资源 / 拖拽排序 / 修改类型 |

**拖拽排序**：

```
拖拽模块 → 计算是否与依赖链冲突：

  拖拽「NLP 专项」到「深度学习」前面 →
    检查：NLP 是否依赖 DL？
      → 不依赖 → 直接交换 ✓
      → 依赖 → 红线提示：⚠️ 不能放在依赖项之前 [取消]

  拖拽子模块「特征工程」到「模型评估」前面 →
    检查：子模块之间无强依赖（它们平级）→ 直接交换 ✓
```

**外科手术式原则**：只调整受影响的依赖链。

```
暂停一个月后：
  → 所有模块的 mastery 按半衰期计算衰减
  → 「机器学习入门」未完成 → 其直接后继「深度学习」解锁推迟
  → 「NLP 专项」独立路径 → 不受影响 → 原计划不变
  → 只插入必要的复习节点，不做全局重排
```
