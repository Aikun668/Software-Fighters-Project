> **创建日期**：2026-07-14  
> **状态**：待用户确认  
> **依赖**：chat-page-layout-design.md（对话页资源生成模式）

---

## 一、设计原则

```
纯展示 + 导航入口 · 资源只在对话中生成
─────────────────────────────────────────
· 工坊 = 资源总览库，不在此处直接生成
· 点击"新建资源"→ 跳转对话辅导页，自动切到资源生成模式
· 资源详情用 Modal 弹窗查看
· 平铺网格 + 搜索，不做分类标签
· 支持 PPT / PDF / Markdown 三种导出
```

## 四、逐区域分解

### 4.1 页面头部

```
📁 资源工坊
对话中生成的学习资料，都在这里汇集

标题：20px bold
副标题：13px regular
```

### 4.2 搜索框

```
┌──────────────────────────────────────────────────────────┐
│ 🔍 搜索资源名称或描述...                                   │
└──────────────────────────────────────────────────────────┘

输入即搜索，实时过滤
匹配范围：资源标题 + 资源描述
清空搜索框 → 恢复显示全部
```

### 4.3 类型标签栏

```
[全部] [📄 文档] [🧠 思维导图] [💻 代码] [🃏 闪卡] [🚀 项目] [📊 可视化]

横向排列，切换时过滤卡片
选中态：背景高亮
未选中：次级文字
```

### 4.4 资源卡片

```
┌────────────────────────────┐
│                            │
│  ┌──────────────────────┐  │
│  │        📄             │  │  ← 类型图标区 (h: 100px)
│  │      (大图标)          │  │     居中 emoji
│  └──────────────────────┘  │
│                            │
│  CNN 入门教程               │  ← 标题 14px bold, 1 行截断
│  从卷积层到经典架构的完整讲解│  ← 描述 12px regular, 2 行截断
│                            │
│  7月13日  ·  12 页         │  ← 元数据行 11px
│                            │
│  📖 查看    ⤓ 导出    🗑   │  ← 操作行（三个图标按钮）
└────────────────────────────┘

宽度：自适应网格，桌面端约 240px
高度：约 240px
圆角：12px
gap：16px
hover：上浮 2px + 边框高亮
```

**6 种类型的图标区**：

| 类型 | emoji | 元数据显示 |
|------|-------|----------|
| 文档 | 📄 | "N 页" |
| 思维导图 | 🧠 | "思维导图" |
| 代码 | 💻 | "Python" 等语言 |
| 闪卡 | 🃏 | "× N 张" |
| 项目 | 🚀 | "项目实战" |
| 可视化 | 📊 | "交互式" |

**操作按钮（hover 显示全部，默认只显示图标）**：

```
📖 查看  → 打开 Modal 查看完整内容
⤓ 导出  → 展开导出选项：PPT / PDF / Markdown
🗑 删除  → 确认弹窗："确定删除「CNN 入门教程」吗？不可恢复。"
```

### 4.5 导航入口卡片

```
┌────────────────────────────┐
│                            │
│                            │
│           💬               │  ← 大图标
│                            │
│       去对话页生成           │  ← 引导文字
│                            │
│                            │
└────────────────────────────┘

与资源卡片同尺寸
虚线边框
hover → 实线 + 文字强调

点击 →

  2. 自动切换输入框模式为「资源生成」
  3. placeholder 变为"输入主题，我生成学习资料..."
  4. 聚焦输入框
```

## 五、导出功能

```

┌──────────────┐
│ ⤓ PPT   (.pptx)│
│ ⤓ PDF   (.pdf) │

Modal 中同样三个导出按钮在底部
```

## 七、数据模型

```
Resource:
  id: number
  type: "document" | "mindmap" | "code" | "flashcards" | "project" | "visualization"
  title: string                    # "CNN 入门教程"
  description: string              # "从卷积层到经典架构的完整讲解"
  content_blocks: ContentBlock[]   # 内容（Markdown/Mermaid/代码等）
  questions: Question[]            # 附带题目（如有）
  created_at: datetime
  page_count: number | null        # 文档/闪卡类型的页数/张数
  language: string | null          # 代码类型的编程语言
  source_conversation_id: number   # 来自哪次对话
```
