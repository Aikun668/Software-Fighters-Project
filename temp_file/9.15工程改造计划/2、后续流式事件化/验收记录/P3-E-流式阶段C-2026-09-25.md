## 二、C1 最小实验（`tests/test_langgraph_stream_spike.py`，6 例）

环境：`langgraph 1.1.2` / `langchain-core 1.2.19`。

| 编号 | 实测结论 | 对设计的影响 |
|---|---|---|
| `SP-01` | `stream_mode="updates"` 逐节点产出 `{节点名: 增量}` | 可作为节点事件来源 |
| `SP-02` | `stream_mode="values"` 每步产出完整状态快照 | 可取出与 `ainvoke` 等价的终态 |
| `SP-03` | `stream_mode="custom"` + 节点内 `get_stream_writer()` 可用 | 后续可发"正在检索"这类主动进度 |
| `SP-04` | ⚠️ `messages` 模式**抓不到**本项目自研 LLM 包装（`OpenAILLM`）的 token | **token 仍走既有旁路**；C 阶段只管节点/状态事件 |
| `SP-05` | ✅ **意外收获**：手工嵌套 `ainvoke`（本项目现状：Workflow 节点里调 `agent.run()`）在 `subgraphs=True` 下**内层节点事件可见且带 namespace** | **无需重写现有嵌套结构**即可拿到分层节点事件 |
| `SP-06` | `astream` 终态与 `ainvoke` **一致** | 等价替换 + 回退路径成立 |

> `SP-05` 是最有价值的发现：最初我按"看不到"写了断言，实测**翻红**，说明内层事件可见 —— 这直接把 C 阶段的改动量砍掉一大半（否则要先重写所有嵌套方式）。

## 三、C2 转换层（`app/events/graph_stream.py`）

新增 `ainvoke_with_events(compiled_graph, input_state, *, emitter=None, config=None)`：

- `emitter is None` → **直接 `ainvoke`**（零额外开销，既有调用点可无脑替换）；
- 传入 emitter → 用 `astream(stream_mode=["updates","values"], subgraphs=True)`：
  - `updates` → 每个节点完成时发 `node.completed`（带 `node` 名、`namespace` 层级路径、`depth`）；
  - `values` → 取**顶层**最后一次快照作返回值；
  - 未拿到顶层快照（如被中断）→ 记 warning 并**回退 `ainvoke`**；
- 事件里带的是**图节点名**（`build_graph` 注册名），不是方法名。

契约 `tests/test_graph_stream_adapter_contract.py`：`GS-A01` 含内层节点的分层事件｜`GS-A02` **返回值与 `ainvoke` 逐字段一致**｜`GS-A03` 不传 emitter 一致｜`GS-A04` 订阅者异常不影响结果｜**`GS-A05` 事件顺序 == 执行顺序**（`outer_first, inner_a, inner_b, wrapped, outer_last`）｜`GS-A06` 不依赖 web 框架。

| 改动 | 说明 |
|---|---|
| `graph_stream.graph_stream_enabled()` | 新开关 `AI_SERVICE_GRAPH_STREAM`：**默认开启**；`0/false/no/off` → 一键退回 `ainvoke` 纯路径 |

`CS-B02`（关闭时无事件源、结果一致）｜**`CS-B03`（Workflow 节点里嵌套调用的 Agent，其内层节点事件汇入同一条流）**。

### ⚠️ 过程中发现并修掉一个真问题：嵌套开流会互相污染

`BaseWorkflow` 接入后，画像 harness 的指纹**首次比对不一致**，排查（含一次性探针）后确认：

- 内层（Workflow 节点里 `await agent.run()`）**也开 `astream`** 时，它收到的 chunk 被父级的
  namespace 前缀污染 → 取不到自己的顶层 `values` 快照 → 走到回退分支（日志里出现
  "未收到顶层 values 快照，回退 ainvoke"）。
- **修法**：新增 `_streaming_active` ContextVar，保证**只有最外层开流**；内层走普通 `ainvoke`。
  内层不开流**不会丢事件** —— 外层 `subgraphs=True` 本来就能捕获内层节点（最小实验 `SP-05` 已证）。
- 修复后：画像指纹恢复一致，回退告警清零。

> 这条正是「先立存证再改结构」的价值：纯 mock/单测全绿，**不改机制也可能悄悄变行为**，只有指纹比对抓得住。
