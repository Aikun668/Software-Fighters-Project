## 五、过程中发现并处理的真问题（本轮最大收获）

1. **A8 `computed_from` 顺序断言曾漏判**。`freshness.computed_from` 若按输入字典顺序输出，跨调用可能漂移。**定位**：`learning_snapshot.py` 的 `build_snapshot` 组装修饰处。**核验**：harness 加了**子序列断言** —— `computed_from` 必须是 `ALL_SOURCES = (active_plan, mastery, profile, graph)` 过滤后的子序列，顺序不可变。**修复**：输出前统一按 `ALL_SOURCES` 过滤定序。

2. **指纹必须排除墙上时钟**。首版指纹含 `generated_at`，两次运行**必然** MISMATCH（秒级差异）。**核验**：`_fingerprint()` 只取稳定业务字段（`status/reason/level/action_kind/entry`）。**修复**：`generated_at` 排除出指纹，可复现性只在**指纹**上比较。

3. **`plan_closure` 曾把两种拒绝边界混为一谈**（预测到、实测确认）。**事实**：枚举内但不允许的组合（如 `resource` + `exercise_done`）→ `validate_combination` → **400**；枚举外 `source_action`（如 `telepathy`）→ pydantic `Literal` 在**模式边界**拦下 → **422**，根本到不了路由体。**修复**：拆成两条独立断言（`s1==400` / `s2==422`），并断言两者响应体均**无 `data`**（拒绝不得携带业务数据）。

4. **reviewer 抓出一条"看似有断言、实则空转"的 HIGH**。原"被拒证据不得污染幂等表"的恢复用例改了 `source_action`，而 `idempotent_key` **包含** `source_action` → 键本就不同 → 断言恒真、**空转**。**修复**：改成**逐字节相同**的幂等键（同 `source_action=manual` / 同 `rec="bad_3"`，只把 `score_or_result` 从 `"不是数字"` 改为 `0.8`），要求 `s4==200` 且 `applied is True`。**注入判别力证明**：临时在 `compute_new_mastery` **之前**插 `mark_seen(key)`，该 case 立刻转 RED，报 `被拒证据不得污染幂等表：同键改正后重提应 applied=True，实际 200/False` + `recovered=200:False:duplicate_discarded:None` → 证明断言**真的有效**（探针已完全回退，净零改动）。

5. **`compute_new_mastery` 的抛错路径未被覆盖**（MEDIUM 缺口）。`manual_correction` 传非数值串 → `EvidenceContractError` → 400。**补向量**：`MANUAL_BAD_SCORE_EV`（`score_or_result="不是数字"`，`s3==400`）。此路径正是"先算后记"设计要保护的场景。

6. **`graph_service.get_graph(course_id, masteries)` 忽略 `course_id`**，恒返回真实 `ai_intro` 10 节点骨架。**推论**：任何 `course_id` 下 `graph_nodes` 非空 → `freshness.computed_from` **恒含 `graph`**。已作为 harness 期望固化；同时是 §七 风险登记项（真实多课程接入时需复核）。

7. **清理 LOW 死代码**：`learning_snapshot.py::_check_action` 中原有 `if "action_kind" not in action` 分支不可达（`kind` 已在此前判过），删除。

### 诚实前提（回答 P2 §八 退出条件 4）

**问题**：学生是否能在不理解系统内部模块的情况下，完成一次"建议 → 学习 → 结果 → 新建议"？

- **Python 侧已具备闭环的"算术与契约"**：给定上下文，能算出建议（Task 4）、能记账证据（Task 2）、能反映新状态（Task 3），且同一输入可复现（§四 13 条指纹）。harness 证明的是"**机制**成立"，不是"**学生**走通"。

- **断点②在前端第一跳**（P0-A 已证）：计划 / 练习 / 资源三个页面的前端入口是静态演示数据，**学生点不到真链路**；且建议卡按决策点 2 不做 UI，学生**看不到**建议，只能由 harness / 人工消费 JSON。
