## 三、同进程 HTTP 字节存证

### 3.1 harness

`_accept_sse_all_endpoints.py`（未跟踪）：同进程 ASGI，覆盖

- **全部 8 个 SSE 端点**（`profile_chat` / `resources_generate` / `tutor_chat` /
  `exercise_generate` / `solve_question` / `unified_chat` / `inquiry_resolve` /
  `inquiry_resolve_plan`）
- **1 个内层异常场景**（`resources_generate` 子生成器抛错 → error + done 边界兜底）
- **3 个下载端点 × 4 档输入**（正常 / 穿越无扩展名 / 穿越带扩展名 / 扩展名不符 / 不存在）
- **SSRF + MIME 探针**（11 组 URL：内网 / 十进制 / 十六进制 / 八进制 / 公网 / data URI / 裸 base64）

每个用例打印 `status` / `content-type` / `bytes` / `sha256` + 原始响应体。

补记：harness 里 `_patch` 起初对所有符号一律包 `lambda:`，撞上 `_EXPORTS_DIR` 是常量而非工厂，报
`TypeError: expected str, bytes or os.PathLike object, not function`。已改为按原值是否 callable
自动选择「包 lambda」或「直接赋值」，两种注入点共用一套。

### 3.2 确定性

同一状态连跑两次，`diff` 逐字节一致 → 存证里无时间戳等易变内容，sha256 可作契约。
