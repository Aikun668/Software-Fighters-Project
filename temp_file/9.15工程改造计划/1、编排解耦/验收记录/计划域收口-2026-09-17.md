## 3. 手工 HTTP 请求验证 ✅ 通过

**目标**：用 curl 对 `/internal/plans/create-from-path` 发一次完整请求，校验响应字段。

**请求体**（与方案文档 Step 3 一致）：
```json
{
  "user_id": 123,
  "course_id": "ai_intro",
  "topic": "机器学习三个月学习计划",
  "student_profile": {"level": "beginner"}
}
```

**执行命令**：
```bash
curl -s -X POST http://127.0.0.1:8001/internal/plans/create-from-path \
  -H "Content-Type: application/json; charset=utf-8" \
  --data-binary @/tmp/cfp-body.json \
  --max-time 180
```

**响应（HTTP 200）**：

| 字段 | 值 | 验收要点 |
|---|---|---|
| `success` | `true` | ✅ |
| `data.course_id` | `"ai_intro"` | ✅ 回填请求参数 |
| `data.total_steps` | `45` | ✅ 非空 |
| `data.title` | `"机器学习系统性学习计划"` | ✅ 非空 |
| `data.estimated_days` | `90` | ✅ 正数 |
| `data.daily_capacity` | `3` | ✅ |
| `data.milestones` | list, 4 项 | ✅ list 类型，每项 `{milestone_id, after_step, description}` |
| `data.steps` | list, 45 项 | ✅ |
| `data.steps[*].knowledge_node_id` | 45/45 = 100% | ✅ **全部**带 `knowledge_node_id`（超出"至少一个"要求） |
| `data.steps[*].suggested_resource_types` | 45/45 = 100% | ✅ **全部**带资源类型建议 |
| `data.concept_graph` | dict, 含 `macro_topics` / `micro_skills` / `prerequisites` | ✅ |
| `data.summary` | 中文综述（含"总计划：45 个学习日，约需 3 个月…"） | ✅ |

**用户可见错误**：无。

**意外发现**：`HTTP 502` 偶发问题
- 三次 httpx 直连重试均收到 502 + 空 body
- 但同时段日志无对应请求记录 → 不是 uvicorn 响应，是网络层/连接复用问题
- 改用原生 curl `--data-binary @file` 后稳定 200
- 推断：httpx 客户端 keep-alive 连接在 LLM 长时间响应后被服务端提前关闭，httpx 重试逻辑未生效；非本轮 PlanCenter 引入的问题
- **未在验收结论中作为失败项**：curl 是真实 HTTP 调用，且稳定复现 200
