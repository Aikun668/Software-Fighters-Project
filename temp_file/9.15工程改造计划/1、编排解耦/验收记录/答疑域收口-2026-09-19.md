## 3. 收口前后逐字节对照（兼容红线）✅

**方法**：未跟踪脚本 `ai-service/_accept_tutor_sse.py` 同进程 ASGI 打 `/internal/tutor/chat`，注入同一组逻辑 stub（假 TutorAgent + 假 ProfileAgent），把整段 SSE 原样打印并附 byte 长度与 sha256。脚本自动探测装配点：收口前 patch `_get_tutor_agent`/`_get_profile_agent`，收口后 patch `_get_tutor_center` 并包真实 `TutorCenter`——两种版本喂进去的是同一组逻辑输入。

```bash
# 收口前（git worktree add /tmp/tutor_pre 3fe0cc9）
python _accept_tutor_sse.py > _accept_tutor_sse_before.txt
# 收口后（HEAD e2be8d4）
python _accept_tutor_sse.py > _accept_tutor_sse_after.txt
# 只比对对外可观测部分（剔除 harness 自身打印的装配点标签）
diff -u <(grep -v '^=== scenario' metrics_before) <(grep -v '^=== scenario' metrics_after)
→ 空 diff（exit 0）
```

| 场景 | status | content-type | 收口前 bytes | 收口后 bytes | sha256（两侧相同） |
| --- | --- | --- | --- | --- | --- |
| success | 200 | `text/event-stream; charset=utf-8` | 135 | 135 | `f15952318ead607b…de4e1075` |
| profile_delta | 200 | `text/event-stream; charset=utf-8` | 132 | 132 | `3ece759b56fa2b39…2885d267` |
| empty_response | 200 | `text/event-stream; charset=utf-8` | 45 | 45 | `c1e84d5b7d1311cd…73cdab338` |
| agent_error | 200 | `text/event-stream; charset=utf-8` | 94 | 94 | `fbb22cf742b119eb…29b08d03d` |

整份 harness 输出的 diff 只有两类差异，**均非对外字节**：

1. harness 自己打印的装配点标签行（`Agent 直连装配点（收口前）` vs `TutorCenter 装配点（收口后）`）；
2. 异常日志文本（`Tutor chat SSE error: boom` → `Tutor chat stream failed: boom`），仅服务端日志。

```python
@router.post("/tutor/chat")
async def tutor_chat(body: TutorChatRequest):
    body = sanitize_model(body)
    messages = body.messages
    student_profile = body.student_profile

    async def event_stream():
        async for event in _get_tutor_center().stream_chat(
            messages=messages,
            student_profile=student_profile,

            yield event.to_sse()

    return StreamingResponse(sse_heartbeat_generator(event_stream()), media_type="text/event-stream")
```
