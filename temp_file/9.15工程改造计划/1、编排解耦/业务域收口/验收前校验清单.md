# 验收前校验清单

> **用途**：用于每一次"业务域收口"迁移的提交前与验收前检查。它不是测试替代品；它防止出现"文件更整齐，但接口、业务结果或真实运行行为已退化"的假完成。

## 使用方式

1. 改代码前填写"迁移范围"和"现状基线"。
2. 每完成一个独立任务，完成结构与离线测试检查。
3. 声称完成前，完成真实接口、工作区与人工结果检查。
4. 任一未执行项必须写明原因；未执行不等于通过。
