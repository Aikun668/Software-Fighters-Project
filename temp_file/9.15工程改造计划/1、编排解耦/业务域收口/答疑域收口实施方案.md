> 目标：把 `/tutor/chat` 从「API 手拼流式回答」收窄为「校验 → 一个 Center 调用 → 序列化」，建立文档既定的 `TutorCenter`，为 P2「`/api/chat` 普通输入稳定走 `TutorCenter`」铺路。

## 零、现状摸底结论（先于方案）

### 0.1 `tutor/chat` 是遗留第二入口，不是当前活跃主入口

| 事实 | 证据 |
| --- | --- |
| Java 定义了 `PythonClient.tutorChatStream()` 但**无任何调用方** | `backend/src/main/java/.../client/PythonClient.java:114`，全仓 grep 仅 1 处命中（定义行） |
| 前端只调 `/api/chat` | `frontend/src/api/chat.ts:16`；`frontend/src/views/AITutor.vue` 无任何 API 调用；`ai-tutor` 路由指向 `ModulePreview.vue` |
| 答疑的真实主链路走 `/api/chat` | `ChatController.chat()` → `unifiedChatStream` → Python `ChatCenter.route()` NORMAL_CHAT 分支 → `ResultAgent` → `AutoCenter._run_tutor` → `TutorAgent` |

**结论**：用户体感的"答疑主入口"是 `/api/chat` 的 NORMAL_CHAT 分支（已在上轮随聊天域收口进 `ChatCenter`）。`/tutor/chat` 是**功能等价但实现独立的遗留第二入口**，也是 API 层最后一处"手拼流式"（除 `/profile/chat` 与路径摘要）。本轮收口它的价值是：消除第二实现 + 建立 `TutorCenter` 作为 P2 的地基。

### 0.2 `/tutor/chat` 现状（`internal_api.py:421-465`，45 行）

API 层当前持有四件业务事：

1. **Agent 装配**：`_get_tutor_agent()` → `TutorAgent(use_mock_llm=_get_mock_flag())`
2. **假流式 token**：`agent.run()` 完整跑完后，把 `response` 按 4 字切片、每片 `sleep(0.03)` 发 `{"type":"token","content":...}`（`_sse_stream_chunks`）
3. **后台画像提取**：`_get_profile_agent().extract_and_merge(student_profile, messages)` → `changed` 为真时把 `profile` 放进 done 的 `profile_delta`；异常只记 warning，不影响主回答
4. **终态拼装**：`{"type":"done","domain":domain}`（+ 可选 `profile_delta`）；异常 → `{"type":"error","content":"答疑失败，请稍后重试"}` + `{"type":"done"}`

### 0.3 两条 tutor 语义**不同**，不能顺手合并

| 维度 | `/tutor/chat` | `/api/chat` NORMAL_CHAT |
| --- | --- | --- |
| Agent 装配 | `TutorAgent(use_mock_llm=mock)` | `AutoCenter` 内 `TutorAgent()`（默认参数） |
| token 流 | **假切片**（跑完后 4 字/0.03s） | **真流式**（`_on_token` + Queue，`ResultAgent` 内） |
| 图解增强 | 无 | 有（`AutoCenter._maybe_visualize`） |
| 事件形状 | token* → done | center_start → token* → center_end → finalize → done |
| 画像增量 | **有**（`extract_and_merge`） | 无 |
| `conversation_id` | 未传（模型未声明该字段，Java 发了也被丢弃） | 传入 `task.context` |

### 0.4 上轮资产可直接复用

- `events/types.py` 已有 `token_event` / `error_content_event` / `flat_done_event`（练习域轮次新增），**本轮无需新增任何事件类型**，SSE 字节天然一致：`flat_done_event({"domain": d, "profile_delta": p})` → `{"type":"done","domain":d,"profile_delta":p}`。
- `ResultAgent`（`app/centers/result_agent.py:111-156`）已有成熟的 `asyncio.Queue + on_token` 流式桥接可参考（本轮不需要，见决策 1）。
- `TutorAgent` 已支持 `_on_token` 透传（`tutor_agent.py:353-375` + `base_agent.py:124-139`），真流式能力现成。

### 0.5 观察项（记录，不在本轮范围）

- `conversation_id`：Java 发送但 `TutorChatRequest` 未声明 → 静默丢弃（Pydantic 默认忽略额外字段），故 tutor 端点不加载对话摘要。属功能缺口，非收口范围。
- `sanitize_model` 只写回顶层 str 字段，嵌套 `messages` 的 content 不写回（`prompt_guard.py:42-62`）；`sanitize_for_llm` 只过滤英文注入模式（"ignore all previous instructions" → `[filtered]`，中文"忽略以上所有指令"不命中）。现状即如此，收口后行为不变。
- 收口后 `_sse_stream_chunks` 仍被 `/profile/chat`（line 370）与路径摘要（line 1948）使用 → 本轮**不能删**。

## 一、这次要解决什么

### 当前调用链

```text
API /tutor/chat
  ├─ sanitize_model
  ├─ _get_tutor_agent()          ← Agent 装配在 API
  ├─ event_stream():
  │    ├─ agent.run(messages, student_profile)
  │    ├─ 4 字假切片 + sleep(0.03) → 手写 SSE token 帧
  │    ├─ _get_profile_agent().extract_and_merge(...)   ← 业务工作在 API
  │    ├─ 手写 done 帧（domain / profile_delta）
  │    └─ except → 手写 error + done 帧
  └─ StreamingResponse(sse_heartbeat_generator(...))
```

### 迁移后调用链

```text
API /tutor/chat
  ├─ sanitize_model + 400 校验（模型层）
  ├─ async for event in _get_tutor_center().stream_chat(...):
  │      yield event.to_sse()
  └─ StreamingResponse(sse_heartbeat_generator(...))

TutorCenter.stream_chat()
  ├─ TutorAgent.run(messages, student_profile)
  ├─ token*（分片规则在 Center）
  ├─ profile_agent.extract_and_merge(...)  → 可选 profile_delta
  ├─ done(domain, profile_delta?)
  └─ 异常 → error(文案) + done
```

## 三、兼容红线（先于技术方案，最高优先级）

真实消费方：Java `PythonClient.createSseEmitter()`（逐事件透传 + done 回调）。**无活跃调用方反而要求更严格的兼容**——Java 侧随时可能接线，P2 也会复用同一语义。

**成功路径**（逐字节）

```json
{"type": "token", "content": "..."}          // 多次，4 字一片，sleep 0.03
{"type": "done", "domain": "ai"}              // domain 恒在；profile_delta 仅在 changed 时出现
```

**画像增量**

```json
{"type": "done", "domain": "ai", "profile_delta": {...}}
```

- 仅当 `extract_and_merge` 返回 `changed=True` 才带 `profile_delta`
- 提取抛异常 → 只记 warning，`done` 不带 `profile_delta`，主回答不受影响
- 提取发生在 token 发完之后、done 之前（顺序固定）

**失败路径**

```json
{"type": "error", "content": "答疑失败，请稍后重试"}
{"type": "done"}
```

- `agent.run()` 抛异常 → 无任何 token，直接 error + done（两段）
- 空 `response`（sanity 判失败时 `TutorAgent` 返回 `response=""`）→ 无 token，直接 `done{"domain":...}`（**不是 error**，现状即如此，必须保持）

**400 分支**：`messages` 缺失/空列表 → 现有 `RequestValidationError` 处理器返回 400（`TUTOR-C09` 锁定）

## 五、技术方案

### 5.1 事件序列化（`app/events/types.py`）

**零改动**。所需三种帧上轮已具备：

| 帧 | 工厂 | `to_sse()` 输出 |
| --- | --- | --- |
| token | `token_event(chunk)` | `{"type":"token","content":chunk}` |
| error | `error_content_event(msg)` | `{"type":"error","content":msg}` |
| done | `flat_done_event({"domain": d})` | `{"type":"done","domain":d}`（键序 = dict 插入序） |

键序注意：现状 done 是 `{"type": "done", "domain": ..., "profile_delta": ...}`，因此 `flat_done_event` 的入参 dict 必须先 domain 后 profile_delta。

### 5.2 `TutorCenter` 新增（新建文件，约 90 行）

```python
class TutorCenter:
    def __init__(
        self,
        tutor_agent=None,
        profile_agent=None,
    ):
        self.tutor_agent = tutor_agent
        self.profile_agent = profile_agent
        self.token_delay = 0.03     # 现状节奏，测试注入 0
        self.chunk_size = 4          # 现状 4 字/片
        self.profile_extract_on = True   # 测试可关

    async def stream_chat(
        self,
        *,
        messages: list[dict],
        student_profile: dict,
    ) -> AsyncIterator[StreamEvent]:
        """答疑流：token* →（画像提取）→ done{domain, profile_delta?}；异常 → error + done。"""
```

责任分解：

1. `state = await self._tutor_agent().run({"messages": messages, "student_profile": student_profile})`
2. `response = state.get("response","")`；按 `_chunks(response, self.chunk_size)` + `sleep(token_delay)` 发 `token_event`
3. `response and messages` 为真时：`result = await self._profile_agent().extract_and_merge(student_profile, messages)`；`changed` 为真取 `profile`；**异常只 warning**
4. `flat_done_event({"domain": state.get("domain","")} | ({"profile_delta": p} if p else {}))`
5. `except Exception` → `error_content_event(TUTOR_FAILED_MESSAGE)` + `flat_done_event()`
